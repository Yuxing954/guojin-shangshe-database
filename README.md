# 国金商社·线上可视化数据库

消费零售 + 社服电商行业线上数据看板，覆盖酒店、免税、OTA、旅游、餐饮、教育、黄金珠宝、跨境电商、零售、人力资源等板块。

- 数据快照日期：**2026-09-08**（商社-市场观点更新至 2026-09-09）
- 线上地址：https://www.workbuddy.cn/space/d/e51Kr7OH8vsOOL04vTT13F （WorkBuddy 资料库 · 团队空间）
- 版式：浅色 paper 主题、涨红跌绿（A 股配色约定）、极简风格

## 数据表说明

| 数据表 | 内容 |
|---|---|
| 板块跟踪数据（酒店/免税/跨境/黄金/餐饮） | 高频经营指标：OCC/ADR/RevPAR、离岛免税销售额、黄金价格、餐饮收入等，含同比/年初至今口径 |
| 商社-覆盖标的本周行情 | A股/港股/美股约 32 只覆盖标的周度行情 |
| 商社-市场观点 | 券商观点/调研纪要观点库（每周一自动抓取更新） |
| 商社-纪要文库 | 会议纪要存档（支持客户下载） |
| 商社-公司公告 | 重点公司公告跟踪 |
| 商社-行业景气数据 | 行业月度景气指标 |
| 商社-业绩与财务跟踪 | 上市公司定期报告业绩跟踪 |
| 商社-标的池与估值跟踪 | 标的池与估值指标 |

## 数据来源

- 行情与财务：Wind 万得金融数据接口
- 宏观与行业：国家统计局、行业协会、酒店之家(STR) 等
- 观点与纪要：券商研报、知识星球「水木调研纪要-2.0」（三层关键词过滤后入仓）

## 更新机制

- 行情数据：按周刷新（Wind）
- 市场观点：每周一 08:00 云端定时任务抓取更新
- 板块经营数据：随数据发布节奏更新
