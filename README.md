# 国金商社·线上可视化数据库

消费零售、社会服务与电商行业的研究数据看板，覆盖酒店、免税、OTA、旅游、餐饮、教育、黄金珠宝、跨境电商、零售及人力资源等板块。

- 数据快照：**2026-09-08**；市场观点更新至 **2026-09-09**
- 主看板：[index.html](./index.html)
- 实时市场页：[dashboard.html](./dashboard.html)
- 视觉规范：浅色 paper 主题；A 股惯例为涨红跌绿

## 数据范围

| 类别 | 数据集 | 内容 |
|---|---|---|
| 行业高频 | 酒店、免税、跨境电商、黄金珠宝、餐饮茶饮 | OCC、ADR、RevPAR、离岛免税销售额、黄金价格、餐饮收入等经营指标，含同比及年初至今口径 |
| 市场 | 覆盖标的本周行情、Wind 市场快照 | A 股、港股及美股覆盖标的行情与指数表现 |
| 研究 | 市场观点、纪要文库 | 券商观点、调研纪要 |
| 行业与公司 | 行业景气、业绩与财务、标的池与估值 | 月度景气指标、定期报告表现及估值跟踪 |

数据清单见 [data-manifest.json](./data-manifest.json)。

## 项目结构

```text
.
├── index.html          # 主看板：行业与公司数据浏览
├── dashboard.html      # 实时市场与分时/K 线展示
├── data-manifest.json  # 数据集目录
├── data/               # CSV 数据表及市场快照
└── update/             # 知识星球增量同步工具
```

## 数据来源与更新

- 行情与财务：Wind 万得金融数据接口
- 宏观与行业：国家统计局、行业协会、酒店之家（STR）等
- 观点与纪要：券商研报、知识星球「水木调研纪要-2.0」

更新节奏：

- 行情数据按周刷新
- 市场观点计划于每周一 08:00 更新
- 行业经营数据依各数据源披露节奏更新

## 更新工具

`update/` 用于将知识星球的商社相关内容增量抓取、筛选、写入资料库并导出至本仓库。使用方式及依赖见 [update/README.md](./update/README.md)。
