# 全站工作台设计规范

行业、宏观、重点公司、观点纪要、行情、日历及工具页面共用 `scripts/workspace-design.css`，在页面专用布局样式之后加载，页面通过 `data-design="workspace"` 声明使用。研究产品及日报正文保留独立报告版式。

| 元素 | 统一规格 |
| --- | --- |
| 字体 | 系统无衬线，中文优先苹方 / 微软雅黑 |
| 页面标题 | 26px / 36px；手机 22px / 32px |
| 卡片标题 | 16px / 24px，600字重 |
| 数据读数 | 28px / 38px；手机 24px / 34px |
| 表格 | 13px / 22px，数字等宽 |
| 筛选控件 | 40px 高、8px 圆角；桌面 14px、手机 16px |
| 次级页签 | 浅色分组底、白底选中、强调色文字 |
| 卡片 | 白底、12px 圆角、16px 内边距、细边框 |
| 间距 | 12px 控件间距、16px 卡片间距、24px 区块间距 |

布局、数据系列颜色、语义状态和数据口径仍由各模块维护。共享规则不裁切内容，不隐藏错误、来源或数值；不改变宏观卡片的固定字段槽位。顶级分类保留下划线导航。

验证：`node scripts/check-site.cjs`、`node tests/workspace-design.browser.cjs`，后者覆盖20个页面与1440/1024/768/390宽度。宏观卡片额外运行 `node tests/macro-dashboard.browser.cjs` 检查中美两组及1920/1440/1024/768/390宽度。
