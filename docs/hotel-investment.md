# 酒店供给与住宿餐饮投资

页面入口：`hotel-dashboard.html#view=structure&mode=change`。

## 供给同比

- 酒店数量、房间数量和连锁房量：本周数值 / 上年相同源表周号数值 - 1，以百分比展示。
- 房量连锁率：连锁房间数量 / 全部房间数量。变化为两期连锁率之差 × 100，单位为百分点，不计算连锁率的相对增长。
- 默认基期为去年同周号；卡片和表格可以使用页首手选的上一年基周，并标为“对比变化”。趋势始终按每期去年同周号计算。
- 全国供给使用 `hotel_supply_weekly.csv` 中全国、全部酒店行，包含15间以下酒店。分酒店规模表逐档取相同口径基期，不混用15间及以上房量。
- 经营概览内的全国和城市规模，以及15间及以上的分档次规模，也跟随同比/绝对值开关。
- 缺少本期、基期，或计数基期为0时同比为空；缺少分子、分母或分母为0时连锁率为空。连锁房量不得大于全部房量。

## 固定资产投资指标

| 项目 | 口径 |
|---|---|
| 审定名称 | 中国:固定资产投资额:住宿和餐饮业:累计同比(%) |
| Choice代码 | EMM01013000 |
| 发布机构 / 转引方 | 国家统计局 / 东方财富Choice |
| 地区及范围 | 全国，住宿和餐饮业合计，固定资产投资不含农户 |
| 原生频率 | 月度，1—2月合并发布，其后为年初至当月累计 |
| 同比单位 | %，直接保留发布序列，不再对增速求同比 |
| 金额单位 | 亿元；未取得的金额保留null，CSV为空 |
| 本次获取日期 | 2026-10-10，北京时间 |
| 本次历史范围 | 2017-02至2026-08，共106期 |
| 最新累计同比 | 2026年1—8月，-15.1% |

原始回执未给出每期发布日期，`release_date`留空。获取日期不能作为发布日期。选择历史酒店周时，投资只保留结束日期不晚于该周的累计数据期；这是按数据期间对齐，不是“当时已发布”的历史版本回测。

住宿和餐饮业包含餐饮投资，不是纯酒店行业投资；投资额也不是开业房量。周度酒店供给与月度累计投资分别绘图、保留各自频率及单位，不将月度增速插值为周度，不由两项增速推断新增房量或开店日期。

同期累计金额本次未从有效查询取得。金额请求曾返回累计同比或住宿餐饮GDP，因指标不符而拒绝入库。已核验的2017年全年完成额6107亿元录入2017-12对应行，其来源为国家统计局公报表4；原文金额按亿元取整。不能利用历年累计同比链式倒推当前完成额。

固定资产投资发布同比按可比口径计算，基期可能修订。原披露金额间的直接比值不保证等于官方发布同比，因此保留发布同比，不用旧金额重算替代。

## 维护

1. 使用已连接的Choice宏观工具查询准确指标名、代码和2017-02至当前的完整月度历史。不得以GDP、年度增速、全行业投资、单独住宿业或单月同比替换。
2. 将真实工具JSON回执保存到本次本地临时目录，运行 `python scripts/import_hotel_investment.py --receipt <回执路径> --checked-at YYYY-MM-DD`。脚本只接受审定的月度同比行和单一代码；重复月份、错误指标、非有限值及未来期间会报错，失败保留原文件。
3. 增量保留历史及已有官方金额、接受同指标修订；短回执不能清空早期历史。金额需单独核验原始披露和单位后入库。查询失败保留旧数据并报告失败，不冒充更新成功。
4. 运行 `node tests/hotel-metrics.test.cjs` 和 `python -m unittest discover -s tests -p test_hotel_investment.py`；核对JSON/CSV一致、月份连续性、缺失金额仍为空、源酒店CSV未改变及实际页面。
5. 只有数值、期间、来源或状态有变化时才通过GitHub连接器发布；仅检查时间变化时不提交。与酒店周度更新共用已有任务，月度指标没有新一期时保留原历史。

文件：`data/hotel-investment-monthly.json`（页面及元数据）、`data/hotel-investment-monthly.csv`（可下载底稿）。投资文件独立于宏观核心及消费专题的共用历史，不修改其他模块定义。
