# 长江三峡游轮月度运行数据

覆盖2024—2026三个自然年：2024-01至2026-09共33个月，33个月均有当月核心指标；2024-01已于2026-10-23核对官网快讯。2026年10月尚未结束，不补入未来月份。

统计对象为长江三峡游轮行业运行情况，不是上市公司三峡旅游的经营数据。发船量单位为艘次，客运量单位为万人，平均载客率按床位计。

总量历史以媒体或论坛转引为主；2024-01已核验官方快讯，2026-10-23新增结构和船公司表已取得官网原始月报归档。逐期保留链接、转引层级和发布日期；2026-03当月载客率由券商研报转引，2026-02由论坛转引，待官方原文复核。

同比沿用来源披露；“为上年同期X%”转换为同比X-100%。载客率同比以百分点记，不是相对增幅。不用已舍入客运量重新计算同比。

累计值直接采用披露，不对月度值机械加总；累计载客率直接采用披露，不取月度载客率平均值。1月累计与当月一致。未核实项目为null，明确披露的零值保留0。

2024-05累计载客率及其同比缺失；2026-01同比缺失。非跨夜明细仅收录已核实披露，其他留空。

2024-02初披累计244艘次、3.89万人，与3月累计739艘次、13.76万人减当月496艘次、9.9万人不一致。2025年2—3月同比隐含的上年载客率也与2024年初披值不同，版本或口径差异原因未核明，未混用基期或回改历史。

累计与当月存在其他衔接差异，如2025-07非跨夜累计230艘次与6月181加7月51不一致；2025-09及12月、2026-06至08月发船累计存在衔接差异。保留原文数值，不强制配平。

2026-05非跨夜累计74艘次、1.36万人与4月相同，但当月48艘次、0.65万人；原转载存在明显衔接异常，数值留存并标记，不据此推算。

省际非跨夜游轮为来源标注的“其中”项，不能加回总量。2024年相关月度明细未完整取得，跨年比较需注意统计覆盖变化。

## 2026-10-23 游客结构与船公司明细

新增 `data/tourism/three-gorges-details.json` 与同源 CSV，页面直接读取预先核验的月度值。原始发布方为重庆航运交易所、重庆邮轮中心；官网归档读取入口为 `https://www.cse.net.cn/#/infodetail/<infoId>`，公开检索接口为 `/api/InfoContent/showInfoInSearch.do`，正文接口为 `/api/InfoContent/showChooseInfo.do`，配图为 `/api/file/loadFile.do?id=<fileId>`。

覆盖2024-01至2026-09的33个月槽位，取得30张船公司月度表、28张单月六档年龄图及逐月客源文字披露。快讯未提供六档年龄与船公司表时留空。2026-01仅取得境外游客占比4.48%，不从舍入比例反推人数。2024-01与2025-01国内人数按原始总人数减境外人数测算，逐字段保留公式。2024-02船公司原表“人”转“万人”。

2024、2025年12月年报的年龄和客源结构属于全年，单列 `annualRecords`；公司表同时有12月和全年，只提取12月列。公司维度沿用用户图中的七家湖北籍省际游轮企业，排除“省际非跨夜”另列项目；未列示企业保留null，明确披露0.00保留0。宜昌交运占比用官方披露，同比由两年同月客运量测算，含原披露舍入误差，基期缺失或为零时不计算。

各月记录保留官方原文、发布日期、具体年龄图和公司表URL。浏览器截图与OCR仅辅助提取；正式值人工对照原图核验，OCR不直接覆盖数据。新增数据检查为 `node tests/cruise-details.test.cjs`。

### 子看板分析口径（2026-10-23）

同页增加“客群与季节”和“公司竞争”，用 `#view=audience`、`#view=operators` 直达；行业页面嵌入后保留所选子看板。两页共读既有 `three-gorges-cruises.json` 和 `three-gorges-details.json`，分析计算集中在 `scripts/cruise-analysis-model.js`，不建立第二套原始数据。

客群页：60岁以上、18岁以下占比的分母为国内游客；18岁以下为原图12岁以下与12—18岁两档相加，任一缺失则不计算。境外占比的分母为全部游客，沿用披露比例；境外人数同比由两年同月已舍入人数测算。所有“较上年同月”占比变动以百分点表示。季节图按同一月份对比最近三个已收录年份，不取年度平均，不使用年报年龄和客源累计值补12月单月。2024—2025全年结构仍只保留在annualRecords。

公司页：仅比较原图七家湖北籍省际游轮企业，不包含省际非跨夜项目；不是完整长江游轮船公司排名。样本位次分母为当月有数值的企业数，缺失不参与排名，明确0参与；并列值采用相同位次。宜昌交运行业份额沿用官方披露；其余企业份额=当月公司客运量÷当月行业客运量，标“测算”，未将七家公司归一化为100%。份额变动=本月份额减上年同月份额；公司同比=当月公司客运量÷上年同月公司客运量-1；较行业增速=公司测算同比减行业原披露同比。基期缺失或非正不算同比，不使用舍入客运量重算行业披露同比。

趋势仅显示所选分析月份及以前的记录；来源缺期断线，不补零、不前向填充。分析CSV保留披露/测算/缺失、当前和基期来源、原始计算输入以及行业分母来源。各企业份额混有舍入误差，不能用其反推真实人数。图上数值开关在切换月份、趋势范围及窗口宽度时保留选择。

验证：`node tests/cruise-analysis.test.cjs` 核验分母、同比、百分点、排名样本及缺失；`node tests/cruise.browser.cjs` 覆盖原总览和新增子看板的切换、显示数值选项与移动端布局。

新增月份需逐项保留来源链接、来源层级、发布日期和字段来源。先补原始月报，再补媒体转引；若修订既有值，应保存旧值、修订日期及依据。不得按后期同比反推覆盖原披露。CSV由JSON同源导出；缺失导出为空。运行 `node tests/cruise-data.test.cjs` 和 `node tests/cruise.browser.cjs`。
