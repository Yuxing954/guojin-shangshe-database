# 财报日历
入口：`earnings.html`；全站一级导航“财报日历”。沿用 `site.css`、`site-shell.js`、`SiteData` 与 `data-manifest.json` 的静态数据读取方式。GitHub Pages 从 main 发布；无独立应用后台、浏览器数据接口或凭证。

## 功能与口径
- 月 / 周 / 列表；搜索名称、代码、行业与公告标题，筛选报告期、行业、市场、财报类型、公告类别、披露状态和关注公司。筛选、视图、日期和历史开关保存在 URL，可分享和刷新恢复。
- `expected` 是来源提供的最新预约披露日；`reservations` 保留首次预约及变更，`announcedAt` 为预约通知发布日期。港股董事会业绩发布安排按通知原文登记，不能推算为已披露。
- `actual` 是定期报告 / 正式业绩公告的实际披露日期。`announcementDate` 是该文件的公告发布日期；上交所使用 `SSEDATE`，另保留 `ADDDATE` 为公告上传时间，两者不互相覆盖。
- `kind` 为 formal / forecast / flash；业绩预告、快报只显示“已公告”，不能将预告日期标为正式财报已披露。港股正式业绩公告的 `documentType=results`，不冒充完整中期报告刊发日期。
- 无来源记录时显示“待公布”，不补零、不推算，不用法定截止日替代预约。港股及美股没有查到季度预约时同样待公布；并非断言所有覆盖公司都必须刊发每个报告类型。
- 临近提醒按北京时间和当前筛选计算，支持提前 3 / 7 / 14 / 30 天；关注与提醒天数仅存当前浏览器。ICS 将来源日期作为全天事件，未来预约含 VALARM；导入日历后提醒依日历应用设置执行。没有离线推送、邮件或自动消息发送。
- 列表提供全部报告期历史；详情保留预约、来源核验时间、公告原文、上传时间、原始依据与字段变更。CSV 保留三类日期及来源时间；ICS 只导出存在可核验日期的记录，按当前日期口径导出。
- 原 `sinolink-earnings-v1` 个人记录保留；详情单列“个人旧记录 · 未经核验”，不会合并进公开日期、提醒或已披露状态，也不覆盖原快照。新功能不提供未经核验的日期编辑。
- 页面错误时可重新加载；不会用示例替代真实数据。存储失败提示并拒绝假装保存关注。

- 香港交易所披露易：海底捞、同程2026H1正式业绩公告与董事会通知，2025FY业绩公告。核验公告证券代码、报告期及公告日期；链接为披露易PDF原文。
- 原2026-09-11东方财富妙想历史快照：保留未被官方记录替代的日期与原始表格字段，来源和核验日保持原值；没有原文时标“原文待补”。其中港股字段来源为披露日期，不能推断为完整报告刊发日。

## 更新与历史保护
`node scripts/update-earnings-calendar.cjs --sse 2026`：从上交所网页所使用的公开接口查询沪市覆盖池，按代码及报告期核对，分页到末页，合并并记录字段变化。运行成功后才原子替换快照。请求失败、数据格式变化、空更新、证券/报告期错配、未来实际披露日、删除既有实际日期或不可信来源均终止；既有历史保留。

`node scripts/update-earnings-calendar.cjs --import verified.json`：输入同一version=2结构，sources提供权威URL、核验时间，records提供唯一ID、来源ID、报告期、日期、原文与证据。允许交易所、巨潮、SEC、Wind、东方财富域名；原妙想快照归档仅允许当前仓库的明确URL。导入验证不是内容真实性的自动证明，操作员必须先回查代码、标题、期间与原文，不能把模型估算写入输入文件。港股/深市/美股更新通过已核验的导入文件；尚未实现这些市场自动抓取。

所有sources的checkedAt是该来源成功核验时间，各条updatedAt独立保留；快照updatedAt为成功合并时间，不冒充所有市场已同步。更新流程默认由维护者执行并走PR检查，未新增凭证或系统安装。
