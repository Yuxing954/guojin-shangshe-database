# 国金商社数据库｜网页编辑与外观验收规范

## 当前实现：Tabler 原生页面（2026-11-25）

本轮按用户要求完整重建界面，只保留已有数据与分类、统计口径。当前外观母版为 [Tabler Admin Template](https://tabler.io/admin-template) 的默认浅色双层横向导航，使用未改写的 Tabler 1.7.5 CSS 和 JavaScript。旧深色侧栏、嵌入业务 iframe、阅读侧栏及各层覆盖样式已退出新入口加载。

### 文件职责

- `scripts/vendor/tabler/`：锁定版本的原版样式、组件脚本和许可证，来源与校验值见同目录 README。不要在 vendor 文件中追加项目样式。
- `scripts/tabler-app/app.js`：品牌、双层导航、页面骨架和模块路由。
- `scripts/tabler-app/common.js`：原生表格、SVG 趋势、来源弹窗、导出、缺失与失败状态。
- `scripts/tabler-app/app.css`：仅保留图表、全文阅读、品牌和必要尺寸适配；颜色、字体、间距、表单、按钮、卡片和表格使用 Tabler 原生变量与组件。
- `scripts/tabler-app/{home,industry,macro,company,research,daily,market,explorer}.js`：业务展示。原有纯模型负责分类及统计定义，原始 `data/` 文件保持独立。
- `scripts/build-tabler-pages.py`：生成统一入口；修改依赖后运行此脚本，避免不同入口加载不同版本。

旧 `site.css`、`site-shell.js`、`workspace-design.css`、`*-design.css` 和旧界面渲染脚本不作为新页面母版。保留在仓库的旧模型、导入程序及历史测试供数据流程和历史追溯使用，不得重新挂到新入口上。

## 编辑范围

| 任务 | 允许修改的内容 | 对照对象 |
| --- | --- | --- |
| 数据或正文更新 | 沿用模块现有导入流程，保留界面和统计定义 | 同一筛选下的前后数据 |
| 单板块改动 | 对应模块及必要共用组件 | 原生 Tabler 同类卡片、表单、表格 |
| 共享组件改动 | 共用组件及实际调用入口 | 各主要页面类型、五档屏幕宽度 |
| 新专题 | 新增业务模块、路由与数据说明入口 | 已有原生业务页 |

外观修改先明确入口、页签、筛选和预计变化；用真实数据核对，禁止把缺失补成演示数据。

## 数据与文案

- 界面以数据、图表、表格和操作控件为主，标题、表头、单位和短标签表达必要信息。
- 保留单位、币种、数据期间、发布日期、行情时点和来源；累计/单季、全店/同店、季调/未季调及原始/转引/测算必须可辨认。
- 缺失值显示 `—`，真实零值显示 `0`。入住率变化按百分点处理；不使用舍入后的值替代披露的同比。
- 研究正文、纪要全文和原始披露不得因精简界面而删改。原文与摘要分别提供，附件保留原件入口。
- 详细口径、数据覆盖和核验记录通过 `data-notes.html`、原始数据目录或来源弹窗访问。页面不添加重复说明段落。
- 筛选后，图表、表格、来源和导出范围应一致；导出保留全部相关字段和来源，不能只导出首行字段或当前分页。

## 外观与交互验收

| 对象 | 要求 |
| --- | --- |
| 导航 | 只有一套主导航；手机可展开；选中态明确；菜单使用原版组件交互 |
| 内容区 | 标题、筛选、卡片、图表和表格共用 Tabler 容器边界 |
| KPI | 同组等宽等高；主数值位置固定；可选字段、预测与缺失不得改变尺寸 |
| 筛选 | 标签与控件相邻，窄屏换行，键盘可操作 |
| 图表 | 期间、单位和系列明确；真实缺口断线；鼠标、触摸与键盘可读取数值 |
| 表格 | 数字对齐；宽表在自身容器横滚；长标题可换行；整页不横向溢出 |
| 全文弹窗 | 显示完整正文，支持关闭、复制、下载和原件入口；返回后恢复焦点 |
| 状态 | 加载、无结果、缺失及读取失败分别呈现；失败可重试；部分来源故障保留其他已加载内容 |

宏观中国、美国两组核心卡片必须检查 1920、1440、1024、768、390px；检查全部卡片边界和必要内容，不使用截断或全局隐藏溢出掩盖问题。其他主要页面至少检查桌面、手机及中间断点。官方模板的响应式容器宽度随断点变化，测量以浏览器真实内容区域为准。

## 检查与发布

1. `python scripts/build-tabler-pages.py`
2. `node scripts/check-site.cjs`
3. `node --test --test-concurrency=1 scripts/*.test.cjs tests/*.test.cjs tests/*.test.js`，并运行受影响模块原有 Python 数据校验。
4. `node tests/tabler-native.browser.cjs`。可用 `TABLER_NATIVE_SUITE=core|research|market|layout` 分组，`SITE_SCREENSHOT_DIR` 留存截图。测试使用真实仓库数据；故障场景仅在测试中注入。
5. 浏览器目视核对目标区域，并实际操作筛选、图表、弹窗及下载。旧布局专用 browser 脚本由新的原生套件替代，数据和分类模型门禁继续保留。
6. 发布前仅提交本任务文件；完整重建必须核对新树与基线 `data/` 树相同。主分支若已更新，基于新主分支重新创建提交，保留期间新增的数据。
7. GitHub 检查完成后通过原仓库 GitHub Pages 发布，并在正式地址普通刷新核验。区分本地检查、CI、正式站结果；失败不可写成通过。

具体实现与本次保留范围见 [Tabler 重建记录](tabler-native-rebuild.md)。
