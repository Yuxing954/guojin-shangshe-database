## 城市分线

采用第一财经2025公开名单固定分组，一至四线共209城。2026年原机构停止发布排名和城市分级，因此不标为2026版。原一线4城展示为超一线，原新一线15城展示为一线，二线30城单列；保留城市原始标签。四线只包含原四线90城，不混入五线。普通省级总额不代替城市，直辖市只计一次。

- 等权平均：同期间、同全口径城市官方同比的算术平均，真实0参与，空值和争议值剔除。
- 中位数、25%/75%分位数和正增长占比使用同一同比样本；分位数采用线性插值。
- 可比基数加权同比（测算）：100×[Σ本期金额/Σ(本期金额/(1+官方同比/100))−1]。仅同时有金额及同比且基数为正的城市参与，样本数单列。
- 较上月配对变化：仅对两期均有官方同比的同城市求同比差的平均，单位百分点，不是社零金额环比。
- 趋势固定样本以所选期有效城市为准，某期样本不齐则断线；逐期样本模式允许城市构成变化并在读数中给出城市数。季度末模式只取3/6/9/12月，不把季度数据补成月度。

各组是已取得样本，不是全国完整分线增速。金额加权与等权可能使用不同样本，不能混称同一口径。

## 京沪月度拆解

早期北京、上海主要披露吃、穿、用、烧四类全口径用途。北京还披露商品零售/餐饮收入，上海早期还有批发零售业/住宿餐饮业。北京2026、上海2025起可取得限上细品类表。每期只列当期可取得的维度，不将早期用途分类强行映射为后来的限上品类。

本期金额和官方可比同比用于反推基数：

- 可比基数 = 本期金额/(1+官方同比/100)
- 分项增量 = 本期金额−分项可比基数
- 拉动百分点 = 分项增量/社零总额可比基数×100
- 增量占比 = 分项增量/社零总增量×100；总增量为零时不算占比
- 剔除后同比 = [(总额−所选分项金额)/(总额可比基数−所选分项可比基数)−1]×100
- 残差 = 社零总增量−同一拆解维度的已披露分项增量之和

限上品类残差包括未列商品及餐饮，不能称为全体限额以下。用途、消费形态、行业、城乡为各自独立维度，不混合加总。当前最多4个用途、2个形态或2个行业的金额与总额相差不超过0.02亿元（原始舍入）；同比可比基数还受统计范围调整影响，差额保留。

每年1月未独立发布不构造。北京1—2月合并单列；上海2022—2024年2月原表有真实单月，予以保留，2025—2026年合并表不拆成虚构单月。各地统计范围变动、2026年产业活动单位在地统计及原始精度保持原样，累计差分与累计可比基数推算仅作为明确标注的测算，不能冒充官方当月披露；不能以旧年已公布金额重算官方同比。

北京9月复算仍可验证：总额1259.546亿元，通讯器材增量98.4291亿元、占总增量83.7222%，拉动8.6192个百分点；剔除通讯后同比1.9748%。均为测算，保留完整精度，不沿用文章的舍入增量117.62亿元。

## 城市当月补算（2026-10-22）

按本次用户要求，`RegionalRetail.deriveMonthly` 在模型层从已合并的原始历史补算城市和直辖市当月值，不改原始文件。相邻两期须为同年、同城市、同分类及同范围：当月金额 = 本月累计金额 − 上月累计金额。已披露当月字段优先；字段缺失才补算。1—2月累计只转合并记录，不在缺少独立1月时拆出1月/2月；真实1月累计可转当月。季度、年度频率、缺前月、统计范围不兼容、累计倒挂和已存在争议字段均不填。

当月同比推算 = 当月差分金额 ÷（本月累计金额/(1+本月累计同比/100) − 上月累计金额/(1+上月累计同比/100)）×100 −100。两期金额和累计同比须完整、反推当月分母为正；原有当月金额与差分金额不一致时不补同比。该分母来自累计披露的可比口径，不等于上年原已公布金额；累计金额和增速的舍入误差会放大到单月，统计范围调整也可能影响差分。

页面与下载分别标注累计差分金额和累计基数推算同比；CSV带两期输入、公式、金额/同比属性及两期所有原始来源。城市分线当月统计纳入可用推算同比并显示推算样本数，累计视图不变。地区历史图可切换金额（亿元）/同比（%），推算点的浮层保留测算性质。

当前2026-08有当月金额的城市由5城扩至35城；广州由1—8月7434.18亿元减1—7月6579亿元，得到8月855.18亿元（累计差分测算）。只有同比无金额的城市、仅季度累计的月份仍不足以补齐所有月值，不按城市数补造记录。
