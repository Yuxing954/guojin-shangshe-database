## 首批观察

1. 北京9月社零同比10.3%的反弹集中于通讯器材。以官方附件完整精度测算，社零同比增量117.5663亿元，其中通讯器材98.4291亿元，占83.7222%，拉动8.6192个百分点；剔除通讯器材后同比1.9748%。原文近似值117.62亿元、98.41亿元与完整精度复算略有差异，网页保留本次计算结果。
2. 同期间8月样本中，15个有同比数据城市9正、5负、1持平，中位数0.6%。广州、深圳分别增长2.7%、1.6%，北京、上海分别下降约2.1%、1.0%。这是已取得样本的描述，不代表全部城市。
3. 1—8月限上通讯器材分化明显：深圳同比53.8%，上海为-8.8%。同一品类在不同城市的增长情况不能由北京单月外推。广州原文商品分类的统计范围未另行明确，按“原文口径”单列，未强行并为限上。
4. 北京限上11类中剔除通讯的其余10类合计同比增量约-15.58亿元，其他未列商品及餐饮残差约34.71亿元。原表未将这部分拆成全部限下，不能据此宣称残差全是限额以下贡献。

## 数据和计算

数据文件：data/regional-retail/observations.json。全国宏观共用历史保持原文件；地方记录增加地区、统计范围和品类维度，不覆盖全国指标。

每条 observation 按 regionId、period、basis、category、scope 唯一，包含金额 amount（亿元）、官方同比 yoy（%）及字段级 provenance。金额和同比可来自不同披露，分别追溯；未知值为 null，真实0保留。sources 保存原名、发布机构、URL、获取时间、回执/附件哈希；未返回发布日期时留空。Choice提供的是带中文量级的显示金额，保留原始字符串和精度标签，不据此重新计算官方同比。候选代码为表级集合，未按顺序映射到行。

北京原始金额单位为万元，除以10000换成亿元。单月和累计均直接读取原表，不用累计相减构造单月。2026年1—2月原表单独归 combined，同时保存同期累计，绝不拆出1月/2月的单月值。

限上企业调查范围每年变化，2026年部分地区社零改用产业活动单位在地统计。可比基数按本期金额与官方同比反推：

- 可比基数 = 本期金额 / (1 + 官方同比 / 100)
- 品类增量 = 本期金额 − 品类可比基数
- 拉动百分点 = 品类增量 / 社零可比基数 × 100
- 增量占比 = 品类增量 / 社零总增量 × 100
- 剔除后增速 = (总额 − 剔除品类金额) / (社零可比基数 − 剔除品类可比基数) − 1
- 残差 = 社零总增量 − 已披露非重叠商品分类增量合计

以上贡献及剔除结果均为披露测算，不是统计局直接发布的贡献数据。未列商品、限下和餐饮共同留在残差中。城市分项仅在相同口径下展示，不将全口径餐饮、限上餐费收入和商品分类混合求和。

Choice月度和季度“累计”序列均可记录到期末月份，原生频率单独保留。年度数列、城乡子口径、限上总额及语义不明确序列放入 importAudit，不代填全口径累计。来源差异超出显示精度阈值时保存 conflicts 并将非官方冲突字段留空；后续原始披露核验后再恢复。

北京网页日期元数据出现“9月数据、9月21日发布”等早于报告期结束的异常，与10月21日附件文件名冲突。本次保留 sourcePublishedAtRaw 和说明，releaseDate 留空。不得按抓取日期或文件名猜发布日期。
