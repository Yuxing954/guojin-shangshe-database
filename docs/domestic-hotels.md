# 国内酒店数据库

- 主入口：company-database.html；独立公司对比：domestic-hotel-comparison.html。
- 索引：data/companies/domestic-hotels.json；四家公司按文件存储，共7427条指标，2018Q1—2026Q2。整理日期不代表原公告发布日期。
- 每个指标保留来源网址、原PDF物理页码、同比来源、基期和原披露备注。公开数据没有本地资料路径。
- 不将全部减同店推算独立非同店，不对累计ADR/OCC/RevPAR作差生成单季，不补零，不跨币种连线。

## 默认与筛选

2026-10-21：默认全部酒店、单季度、同比、近3年。主工具栏只有样本、期间、图表、范围；时间起止、地区、档次、经营模式、币种在“更多筛选”中。只有一个可用选项的档次/模式/币种控件不重复显示，当前统计范围与币种保留短标签。

sampleView=3链接保存新选择，首次打开旧链接或旧工作区地址时迁移到新默认，同时保留公司。默认结束期从数据索引读取。近2/3/5年按结束季度向前取8/12/20个季度，自定义起点后切为自定义。重置恢复该公司全部酒店、单季度、同比、近3年及默认维度。

切换公司保留样本、期间、图表和范围，仅清理公司特有的地区、档次、模式和币种。不自动把单季度换成累计。样本改变清理维度，期间改变重新选择对应档次；华住国际EUR/USD分别显示。快速连续切换通过请求序号防止旧响应覆盖最后选中的公司。

锦江同店缺少某季度时保留缺项，并提供“查看累计”按钮；累计仍按3M/6M/9M/FY显示，季度简写26Q2。全部酒店累计使用模型层主口径回退，保留早期有限服务型原始披露。亚朵2023年以前季度同店不倒填，首旅早期如家/原存量与华住停业范围不合并。

## 图表、明细、标识

经营页直接显示三张图；RevPAR宽图，ADR和OCC在宽屏并排、窄屏纵向显示。共用SiteCharts、海外酒店坐标与字体，悬停/键盘/显示数值/来源/当前与完整导出保留。主卡与图上房价、RevPAR按整数显示，OCC一位小数；原始明细、CSV和来源保留原精度。OCC同比为pct。

明细按当前样本、期间、地区、币种、搜索及独立档次/模式筛选；翻页和时间变化不会丢失档次/模式。图表与原始明细的筛选互不冒充统计合计。完整导出仍为全部7427条。

四个标识存为本地资产：锦江/首旅沿用官网原图，华住换为完整“华住 WORLD”集团标识并与公司采用新Logo公告对照，亚朵换为“亚朵集团 ATOUR GROUP”完整字标（环球旅讯公司归档），不再使用亚朵酒店图形。文件、来源网址、核对日期在索引logos.items中；原图不重绘，不修改经营记录。

详细口径集中在data-notes.html#domestic-hotels。没有修改海外模块、原始四家公司指标文件或共享图表实现。
