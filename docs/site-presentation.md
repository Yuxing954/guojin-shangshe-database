# 全站显示规范

所有 14 个页面入口在页面专属样式之后加载 `scripts/site-polish.css`，统一字体、颜色、间距与响应式布局。新增页面也须在 `</head>` 前加载该文件；不要把显示修复写入数据生成流程。

- 正文与说明 14–16px，表格正文 14px、表头 13px；来源与日期一般 13px。行情密集表保留 13px 正文，代码与时点 12px。
- 一级标题 30px（手机 26px），二级标题 20px（手机 19px），核心数值 28–32px。
- 常规筛选、切换和下载按钮至少 40px 高；纪要弹窗原文 16px、1.95 行距。
- 小屏上宽表格、财报月历只在自身容器内滚动。禁止用隐藏整页横向溢出来掩盖布局问题。
- 不改数据值、统计口径、纪要原文件名、下载权限和原文截取逻辑。

后续更新通常只改数据。调整外观优先修改共享样式文件；修改后检查首页、行业、宏观、公司、纪要、行情、财报日历以及专业行业页的桌面和 390px 小屏显示。刷新 `site-polish.css` 的版本参数，确保正式站客户获取新样式。
