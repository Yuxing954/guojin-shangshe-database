# 企业招聘

全国；原始频率为周，按周度日期归属月份。展示2023年11月—2026年10月，2022年11月起的数据用于同比基期。

新增招聘帖数按月求和，不等于招聘人数或在招岗位存量；未对跨月周拆分。

招聘年均薪资为月内周值算术平均，单位元/年；未按招聘帖数加权，不是实际发放工资。

同比=(本月合并值/上年同月合并值-1)×100%；以未舍入数据计算。

本月与上年同月可能分别含4周或5周，数量同比受周数差异影响。

招聘平台覆盖、去重方式及原始薪资加权规则未由接口提供。

两序列各208期，无重复、无缺周；周度原值及数据更新时间保留供复核。
