# CPI跟踪产品

入口 `cpi-monthly-product.html`，原合并月报地址兼容跳转。产品仅展示CPI，标题“YYYY年M月CPI跟踪”，副标题为对应月官方发布日期；字体、配色、标记及原文声明沿用酒店周报。

## 版面

1. 四个核心指标：CPI与核心CPI同比、环比，以及与上月同项的差值，单位为百分点。
2. 原因解释：以国家统计局当月CPI解读为基础，按同比、环比因素压缩整理，不复述顶部总量，不涉及PPI，不添加无证据的驱动判断。
3. 主要拉动与拖累：同比、环比两组官方贡献，单位为百分点。只列明确披露的主要项目，保留约值，不估算缺失权重、不归一化、不构造伪闭合瀑布图。
4. 同比、环比趋势各占整行，图例只标系列名。默认一年每个有效点直接标值；同月两项相同值只标一次，缺失点不连线或补零。超过24期时降低静态标注密度，所有点仍可悬停。
5. 来源及原文声明。删除重复的近期表与价格涨跌清单。

## 数据与维护

共享历史为 `data/consumption-macro/observations.json` 与 `data/macro/automatic-series.json`。新月数据、解读来源、精简点评与贡献项保存在 `data/products/consumption-monthly-insights.json`，不手改全站底稿生成的数据。按主键补充，历史库已含同月时优先历史库，不重复覆盖。

`source` 为统计数据来源；`interpretation` 保留官方解读URL、标题、发布日期、核对日期及原始HTML哈希；`commentSections` 保存同比/环比原因，`comment` 是页面编辑与导出的默认正文；`contributions` 包括 `unit: percentage_point`、`approximate`、`complete` 和 `sourceId`，每行仅含官方项目名与贡献值。项目存在上下级重叠或不是完整分解时不得加总为总CPI。没有对应月解读或贡献时不套用本月结论。

每月在现有宏观统一更新批次中，优先核对统计局首席统计师当月CPI/PPI解读中的CPI部分，仅在新披露或修订时整理短点评与官方贡献；文字先提待复核PR。页面访问不调用AI、不重复生成点评，不创建客户账号或收藏。

保留数据期间、官方发布日期和入库核对时间，零值与缺失分开。PNG为3600像素宽；点评编辑仅当前页面会话有效。
