# 宏观晨报界面

核心指标页按核心读数、最近发布、重点趋势、全部指标研究排列。晨报不增加商社专题入口；原有消费专题、FedWatch、Polymarket 的独立视图继续保留。

- 中国主卡：实际 GDP 当季同比、社零当月同比、制造业 PMI、CPI 同比；辅助读数：城镇调查失业率、M2 同比。
- 美国主卡：实际 GDP、CPI、非农就业、失业率；辅助读数：联邦基金利率、十年期国债收益率。
- 每项读数保留单位、数据期间、显示口径和发布日期。上期必须匹配准确的上月、上季或上年，缺失不跳期；百分比读数的差值用百分点，PMI 用点。日度指标不推算上期读数或变化。
- 最近发布只排列各月度/季度指标的最新观测，使用已提供、有效且不晚于快照截止的 `releaseDate`。获取时间、检查时间和数据期间均不替代发布日期。未知发布日期计数单独显示，不进入发布时间排序；默认最多五行，支持展开全部。
- 重点趋势默认近三年：中国展示社零、PMI、CPI，美国展示 GDP、CPI、非农就业。沿用原始频率和读数口径，不补缺期、不聚合或插值；PMI 在范围允许时显示 50 线，其他图在范围允许时显示零线。
- 趋势图保留键盘焦点、悬停与触摸数据提示。点击卡片、发布行或趋势标题打开完整指标详情；查询、比较、URL 恢复、CSV 和失败重试继续可用。频率与状态位于“更多筛选”，恢复有筛选的 URL 时自动展开。

本次仅改变界面和读取逻辑，没有更新数据源、补填发布日期或另行核验 Choice 实时数据。自动历史中未提供发布日期的指标保持“未提供”。

验证：`node scripts/check-site.cjs`、`node --test scripts/*.test.cjs tests/*.test.cjs tests/*.test.js`、`node tests/macro-dashboard.browser.cjs`。新增校验涵盖发布日期排序、未来/无效日期拒绝、获取时间隔离、准确上期、同比与原值单位隔离、缺期和三年窗口；浏览器检查晨报下钻、折叠筛选、中美切换、五种宽度和既有交互。
