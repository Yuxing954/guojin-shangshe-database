# 酒店集团对比

酒店集团页以ADR为首图，热度指数、房价指数、酒店数、房间数依次展示。每张图同时展示华住、锦江酒店（中国区）、首旅如家、亚朵，不再按单一集团切换，也不再展示四张单独卡片。

默认四条数值折线，仅可切换为同周同比。旧链接中的combo模式自动回到数值对比。每张图独立选择范围和标注。集团颜色跨指标固定，缺失留空，不跨缺期连线、不求和、不归一化。悬浮或手机点击显示四家同周值；来源入口列出四家定位。

数据仍直接读取data/hotel_group_weekly.csv。ADR、热度指数、房价指数分别读取stay_adr、stay_heat_index、stay_price_index，均为入住日期口径；指数保留两位小数。锦江为中国区，其余保留全国集团样本，不作为公司财报或同店口径比较。OCC、RevPAR未披露则不构造。

周次显示26WXX，源数据、链接和同比匹配使用2026WXX。导出包含全部五项指标、四家集团，保留原值、单位、源字段、同比基周和定位。更新沿用现有酒店CSV流程。

旧单集团链接自动转入四家对比，新链接compare=all保存每图范围与模式。验证：node scripts/hotel-groups-model.test.cjs；node tests/hotel-groups.browser.cjs。
