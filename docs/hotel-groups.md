# 酒店集团看板

入口：行业数据 → 酒店 → 酒店集团。

- 财报经营：华住、锦江、首旅、亚朵。默认RevPAR，可切换OCC、ADR、酒店数、房间数、收入与利润。点集团卡片切换趋势；更多指标表折叠显示新开、筹建等当期资料。
- 周度跟踪：直接读取 hotel_group_weekly.csv；ADR使用 stay_adr（入住日期），保留源CSV集团名称和全国样本范围。没有集团周度OCC或RevPAR时不构造数值。
- 默认数值＋同比双轴；显示数值、显示同比独立勾选，范围旁显示。图表沿用全站工具提示、手机点击、标注抽样与自适应规则，不新增横向滑条。
- 公司经营范围各异，不将华住中国、锦江境内有限服务型、首旅全酒店与亚朵含税口径理解成同店排名。期末集团酒店规模可能覆盖全球，来源中明确列示。
- 财务仅使用同范围、单季、人民币序列，不将半年/累计数据作为Q2值。利润列区分归母净利润和净利润。亿元显示转换不改变导出原数和百万元单位。
- 同比复用 CompanyOverviewModel，优先披露同比，否则匹配同单位、币种、频率、范围与期间口径的上年同期。OCC为pct；非正基数仅显示增减额，不放入增速图。冲突或缺基期不强算。
- 每个数字保留报告、页码、单元格、底稿原值、公式、截图定位及核验层级，点击来源或明细数字查看；不把底稿转录称作本轮独立核验原PDF。

## 更新

1. 按现有流程更新公司原始数据与 profiles.json，无需为看板重复录入。
2. 运行 `node scripts/build-hotel-groups.cjs`，生成 data/hotel-groups.json。
3. 运行 `node scripts/build-hotel-groups.cjs --check`、`node scripts/hotel-groups-model.test.cjs` 和 `node tests/hotel-groups.browser.cjs`。
4. 源数据与生成文件一起提交。CI核验源文件摘要及生成内容一致性。

构建只保留配置明确的可比历史序列，并将来源留在精简数据中。原始公司数据库不变，CSV导出使用原始单位与精度。周度CSV无需额外构建；页面直接读取本站文件，缺期留空。URL记录数据类型、集团、指标、期间与范围，行业页可直接恢复。
