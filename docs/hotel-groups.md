# 酒店集团看板

入口：行业数据 → 酒店 → 酒店集团。

仅使用酒店之家集团周度数据，直接读取 data/hotel_group_weekly.csv。四家集团名称保留源表：华住、锦江酒店（中国区）、首旅如家、亚朵。

- 默认最新数据周。每家集团卡片直接展示入住日期ADR（stay_adr）、酒店数、房间数及三项同周同比。
- 点击集团名称或指标行切换单集团趋势；走势图内另设指标选择，卡片始终展示全部三项。范围支持最近12周、近半年、近1年、近3年及全部历史。
- 默认数值＋同比双轴，范围旁独立勾选数值与同比。显示值取整数；工具提示与CSV保留既定精度和原始精度导出。
- 同比匹配上年同周号，未调整节假日错期；缺期留空，基期缺失、零或负数不强算。
- 不将热度指数当成OCC，也不构造周度RevPAR。财报数据通过“重点公司”或页尾财报链接查看，不用于补集团周度数据。
- 来源对话框保留原值、CSV字段、集团、周次、日期及同比基期；批次来源和导入时间见来源与说明。
- 更新沿用现有酒店CSV导入流程。页面直接读取同一CSV，无重复填报或额外构建；公司财报数据保留在重点公司模块。

验证：node scripts/hotel-groups-model.test.cjs；node tests/hotel-groups.browser.cjs。旧财报深链接会规范化为最新集团周度ADR，不显示旧财报值。
