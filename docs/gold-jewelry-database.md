# 黄金珠宝研究数据库

入口：`gold-jewelry.html`。沿用酒店、免税专题的网页框架，以研究总览、终端需求、公司经营、金价与品牌、数据与口径五个页签组织。首页优先展示同比和消费结构，不把报价条数或工具连接状态作为行业指标。不同频率独立标注最新期间。

## 金额、实物量与累计口径

零售额是全国限额以上单位金银珠宝类名义金额，与黄金协会全行业用金量的统计范围不同。不能用二者相除计算行业平均售价，也不直接用金价对零售额除价当作实际销量。统计局同比沿用原始发布的可比口径，不使用前后年公开绝对额重新计算。

统计局1—2月合并披露：开始日为1月1日，结束日为2月末；金额为两月合计，不拆成两条月份。月度图在跨年缺少独立1月时保留断点。金额视图的1—2月点不与单月金额等长解释。

黄金协会原始值为年初至季末累计；第一季累计即单季，其他单季＝当季累计−同年上季累计。只在单位、来源质量、统计范围一致且累计不逆序时计算；缺上季累计或同比基期则留空。单季同比使用同季单季量计算，明确标为计算值，不复用累计同比。衍生单季记录使用实际季度起止日期，保留当季/前季来源；同比再保留上年当季/前季来源。2023年未收录Q3，故Q4累计可用于全年结构，Q4单季量留空。

图表支持金额/同比、单季/累计切换，时间范围筛选、鼠标/键盘数据点提示。表格和CSV保留对应期间、单位、来源URL及计算口径。

## 公司财务和渠道比较

老铺黄金使用港交所2026年中期公告：收入为不含税Revenue、利润为IFRS归母利润、币种为人民币，不混入含税Sales、非IFRS调整利润和妙想返回的港币换算汇总值。库存是6月末余额，经营现金流为半年流量；库存较2025年末变化是环比，不标为同比。271天库存周转为半年口径，不能与2025全年216天直接计算同比。

潮宏基报告摘要第2页已核验收入、收入同比、归母利润、利润同比和经营现金流；毛利率与库存保留妙想转引状态。周大生、老凤祥、中国黄金当前为妙想结构化字段转引，待公司报告原文复核；部分公司的现金余额响应被排除，缺少经营现金流的地方保持null。

经营现金流 / 归母利润仅是研究用计算比率，现金流为集团口径、分母为归母利润，不能称为会计现金转化率。分母非正或输入缺失不算；由平台字段计算的比率同样标为转引计算。不同公司直营/加盟、零售/批发、金条/首饰的业务结构不同，毛利率不作品牌定价能力排名。

港股公司财年经营在独立区块选择，不能与自然年半年数据混成一张期间表。六福内地全部品牌门店不等于六福珠宝门店，同店金额不等于黄金重量；六福定价黄金与周大福定价首饰占比保持不同范围。周大福新开/关闭总数来自四个互斥城市层级相加，标为计算值；不由门店净增倒推新开或关闭。

## 金价与品牌

挂牌价不是成交价，挂牌价差不是毛利率。市场、币种、单位、品类、计价方式、纯度、税费工费与来源独立存储；未知值为null。第三方报价不得因官网入口存在或数值相同而升级为官方。周六福官网观测独立新增，不改写对应第三方记录，其工费与税仍未核清。

同日参考差仅在同市场/币种/单位、Au99.99唯一收盘基准、原始品牌核验、纯度一致和明确工费/税条件时计算，否则说明缺少的条件。现有数据未满足全部条件，保持空白。报价时刻未必同步，不前向填充。

品牌历史固定来源、市场、品类、纯度和核验级别，独立选择；报价表默认看最近同日全部品牌，可筛品牌和日期。开始/结束日期同时筛选品牌与基准历史、明细、导出。无效区间、空结果禁用对应导出；单点不显示涨跌；首末变化使用实际首末观测，不补所选日历端点。

## 文件与采集

- `data/gold-jewelry/research.json`：复核后的需求与公司财务，逐字段来源、原始字节指纹和限制说明。
- `data/gold-jewelry/research-sources.json`：29条官方需求发布的可重跑来源清单。
- `data/gold-jewelry/observations.json`：品牌及原料价格；`company-operations.json`：公司经营；`verification.json`：10品牌与妙想接入复核。
- `scripts/gold-research-model.js`：累计转单季、同比、现金流比率、期间/币种/来源校验。
- `update/gold_research.py`：原始发布采集器，桌面/手机重复表仅在完全一致时去重，冲突拒绝；年、月、季度和全国口径需与任务匹配。
- `update/gold_history.py`：逐日采集上金所与第三方品牌最近历史；`update/miaoxiang_mcp.py`：官方只读协议客户端。

采集→私有原始字节归档→待审阅批次→指标和单位核验→复核后入库。采集器不自动写正库。网络/解析失败单列，不补零。需求29期已逐条验证字节SHA-256，使用更严格解析器重算后与公开结构化数据一致。官方PDF关键页已渲染核对，PDF页码包括封面。

网页原始字节、公司PDF和妙想原始付费响应保存在仓库外本机工作区，公开仓库只保留经审阅数据和指纹；认证头、密钥、配置和付费原始响应不提交。本任务没有制作Excel截图底稿。

## 妙想官方MCP

依据[官方安装文档](https://mxapi.eastmoney.com/mxds/doc/mcp-install.md)，已优先用curl拉取。服务`https://mxapi.eastmoney.com/mxds/mcp`，Streamable HTTP，认证头`em_api_key`。用户授权凭证只保存于本机配置；输出不打印配置、请求头、密钥或错误响应全文，拒绝重定向转发认证头。

已实际完成MCP初始化、发现11个工具和调用，工具包括`mx_macro_data`、`mx_ashare_finance_data`、`mx_hk_finance_data`与公告检索。本轮财务转引字段来自实际结构化MCP回执；需求定位后回到统计局和黄金协会逐条原文核验。

协议成功不代表指标正确。已排除地方统计混入全国同比、不同合约/频率混入Au99.99、现金余额代替经营现金流、港币换算值代替人民币原始报表，以及公告检索未命中的结果。仍需逐字段核验，不把自然语言答案直接入库。Codex CLI配置已识别，当前聊天原生动态挂载仍未验证；实测使用本机MCP协议客户端。
