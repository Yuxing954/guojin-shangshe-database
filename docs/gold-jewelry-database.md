## 研究口径

按原料价格—品牌报价—需求—经营—产品结构组织。挂牌价不是成交价，价差不是毛利率。地区、币种、单位、黄金饰品/金条/回收、一口价/按克、纯度和税费工费分别记录；未知保留null。

同日参考差要求：同市场、同币种单位、Au99.99收盘、品牌原始来源已核验、纯度一致、工费税口径明确；有多个基准来源则先解决冲突。报价时刻未必同步，不前向填充。

需求：国家统计局限额以上金银珠宝零售额不等于全行业销量。1—2月合并口径不拆月；中国黄金协会金饰/金条金币/工业用金分别记录，不与世界黄金协会直接拼接。累计和单季、金额和吨数、官方同比和计算同比分开。

公司：财年标签之外保存期间起止、期间类型、地区、渠道、产品范围和披露日期。六福集团内地全部品牌门店不等于六福珠宝品牌门店；同店金额增长不等于重量增长。周大福定价首饰零售值占比不等于定价黄金占比。净增不逆推出新开/关店；新开/关闭首批直接转录周大福按城市层级的Gross openings/Gross closures。

固定SKU篮子仍待建设。老铺黄金等定价产品须固定型号、规格、材质、重量、渠道、促销条件；新品或规格变化另记，不并入按克牌价序列。

## 文件与原始凭证

- `data/gold-jewelry/observations.json`：品牌、来源、报价和交易所基准。
- `data/gold-jewelry/company-operations.json`：经营字段、官方公告来源与PDF物理页码。
- `data/gold-jewelry/verification.json`：38个查询日期的返回状态、10品牌核验、首批复核凭证、妙想实测结论。
- `data/gold-jewelry/mx-queries.json`：官方MCP工具与查询任务；legacyTool仅用于旧API兼容。
- `update/gold_history.py`：按日取上金所、取第三方最近10条历史，生成待审批次。
- `update/miaoxiang_mcp.py`：官方Streamable HTTP MCP只读客户端。

新网页原始字节、官方公告PDF、平台原始响应保存在本机工作区的仓库之外，公开来源记录保留SHA-256，不提交平台付费原始数据、认证头或配置。官方PDF关键页已渲染核对，物理页码包括PDF封面；网页转录不冒称报告截图底稿。本任务未生成Excel截图底稿。

首次上金所日期范围页实测只返回部分日期，因此采集器逐日请求，并验证返回日期与合约。HTTP获取或解析失败单列；无观测不补0。新批次不自动改写正库，需复核同源重复、冲突和质量后导入。首批复核相同数值不产生第二条基准。

## 官方妙想MCP配置与实测

安装依据：[东方财富官方文档](https://mxapi.eastmoney.com/mxds/doc/mcp-install.md)，已用curl下载。服务：https://mxapi.eastmoney.com/mxds/mcp，StreamableHttp，请求头em_api_key。用户授权的凭证只在本机Codex配置中保存，其他配置保持原样。

握手返回协议2025-03-26、服务mx-ds-mcp 1.0.0，共发现11个工具。客户端只允许明确审阅的金融查数/公告/新闻检索工具，不调用交易或账户操作。

| 实测 | 结果 | 入库决定 |
| --- | --- | --- |
| mx_ashare_finance_data | 贵州茅台请求返回带交易日期与单位的结构化价格 | 用于官方安装文档建议的连通性测试，不写入黄金库 |
| mx_macro_data | 黄金请求返回Au99.99日均价，但混入iAu99.99以及周/月度收盘；精度为0.1元 | 原始响应私有归档，拒绝作为每日Au99.99原文替代 |
| mx_finance_search_notice | 六福年度公告请求返回股份月报和第三季等材料，未命中目标年报 | 仅作为检索线索，另从港交所取原文核验 |

配置已被Codex CLI识别为enabled，但当前聊天工具列表尚未动态加载该服务。实际测试由本机MCP协议客户端完成；不声称本聊天已调用原生挂载工具。下次启动/新会话需确认工具加载状态。协议成功、业务返回成功、指标身份正确、原文核验是不同层次。

运行（密钥不用命令行参数传入）：

```powershell
python update/miaoxiang_mcp.py --codex-config "$env:USERPROFILE/.codex/config.toml" --raw-dir ../private-mx
python update/miaoxiang_mcp.py --codex-config "$env:USERPROFILE/.codex/config.toml" --raw-dir ../private-mx --query-id gold_benchmark --start 2026-09-28 --as-of 2026-10-08
python update/gold_history.py --start 2026-09-01 --end 2026-10-08 --raw-dir ../private-web --out ../review-batch.json
python update/gold_jewelry.py validate
```

优先读取环境变量EM_API_KEY；否则仅在显式指定--codex-config时读取官方服务配置。旧MX_APIKEY/API回退仍保留，但与em_api_key凭证及官方MCP分开，不能相互替代。响应只写私有目录，拒绝重定向转发认证头。输出不打印密钥、请求头、配置、错误响应体或平台全文。查询模板需要明确company、期间；港股财务用company_financials_hk。
