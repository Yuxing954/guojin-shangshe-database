# 重点公司数据库

## 公司研究档案

默认进入公司概览，先展示公司定位和最新规模、RevPAR、收入、利润快照，然后按业务画像、经营跟踪、财务质量、跟踪事项四个章节展开。经营章节可选择披露范围与季度；财务章节可选择研究底稿/原报告或Choice，以及报告期。另设公司对照、历史明细、来源与缺口三个视图。对照支持固定季度和固定财报期间（年度或半年），财务对照可切换Choice与研究底稿，缺少同期间数据时留空，不用上一期替代。净利润与归母净利润分开标明；期末规模和运营指标可能采用不同网络范围，每条来源保留完整定义。

`data/companies/profiles.json` 保存业务画像、代表性序列选择器、结构分母及跟踪问题；`supplements.json` 索引分片中的102条原披露核对记录。首旅和锦江的2026Q2经营、首旅全网络结构和单季财务、华住HWC/HWI结构等来自用户已有的三份PDF。来源哈希、PDF物理页码、原始单位和换算公式均保留；原PDF未上传。亚朵画像和结构来自已入库底稿，没有把业绩会前瞻表述当作实际结果。

读取时按完整业务维度和期间合并，原披露核对记录优先；原底稿保留在原分片文件中，界面及CSV保留原底稿值、定位和来源。原底稿与原披露核对层合并后共4833条记录，其中159条模型预测、12条待核验占位。本轮另加入148条Choice独立财务记录，合计4981条。补充记录共102条，25条与原记录同键合并，77条新增。锦江2026半年报列示的2025Q2全服务型ADR/OCC/RevPAR与旧底稿存在3项差异；标为基期或来源差异，不擅自判定为重述、错误或同一基期。

同比只取上一年同期间、同频率、同币种、同业务和期间口径。入住率同比使用百分点；同比基期为零或负值时只展示增减额。原报告只给同比而未给基期值时标为报告披露，不反推基期。结构比率使用同期间、同单位、同币种的明确分母，差额保留，不归一化；首旅全网络与旧模型中国范围不跨口径拼接。现金、债务和现金流缺失处显示暂无数据。

原披露补充的固定格式更新入口：

```text
python scripts/import-hotel-disclosures.py --source-root "D:\\WORK" --root .
node scripts/company-overview-model.test.cjs
```

此适配器只对应本轮核对的PDF和取数表，运行前检查预设PDF哈希。源PDF变化时拒绝套用旧值，必须重新核对并更新映射。原经营底稿更新与披露补充分开维护，避免原导入器覆盖核对层。

公司页面 `company-database.html` 接入公司目录和逐公司历史索引和分片文件。首批使用用户 WORK 文件夹中的酒店底稿，当前只保留锦江、首旅、华住、亚朵四家公司。它不是全球酒店上市公司全覆盖目录。

## 数据结构

- `data/companies/catalog.json`：公司身份、证券代码别名、指标目录、覆盖区间和按需读取路径。
- `data/companies/hotels/*.json`：逐公司索引；同名子目录中的分片保存经营、拓店、规模、收入利润、现金流、零售与同店历史。
- `data/companies/sources.json`：底稿相对位置、文件SHA-256、导入时间和核验层级。
- `data/companies/issues.json`：底稿冲突、勾稽差异、非当季开关店记录。
- 页面“导出完整数据”读取全部分片生成CSV，包含预测和待核验记录，须按状态筛选。导入器另生成本地CSV备份，仓库不重复保存大体积CSV。

每条观察值包含公司、期间、频率、期间口径、指标、数值、单位、币种、地区、档次/同店组、经营模式、统计范围、状态、来源ID、工作表/单元格或CSV行号、来源报告、PDF物理页码、原始值及可获得的原始公式。身份由来源位置和业务维度生成，不随数值更新改变。

`transcribed` 只表示从底稿准确转录，不表示本轮已经核验原始披露；`derived` 表示底稿中推算值；`forecast` 为模型明确标为E的2026—2028列；`pending` 为超出已收录实际报告期间的零值占位等。页面默认显示转录及推算历史，预测和待核验期间需单独开启。勾稽差异及冲突通过来源详情展示，未改写源值。

## 更新

使用Python和openpyxl只读导入，不保存或修改原工作簿：

```text
python scripts/import-hotel-company-data.py --source-root "D:\WORK" --root .
python scripts/test_hotel_company_data.py
node scripts/company-database-model.test.cjs
node scripts/site-data.test.cjs
node scripts/resource-model.test.cjs
```

这是显式手动更新入口，不是已安排的自动同步任务。导入器是首批固定格式适配器，新增公司/指标或来源表布局改变时需先核对表界、单位、期间和分类映射，再扩充适配器。不得按单元格颜色或文件修改时间猜测实际报告期。数据目录和观察值结构可复用于其他重点行业。

发布前检查源文件哈希、每条原始值与来源位置、重复序列键、实际/预测状态和前端筛选。GitHub读写使用连接器；基于最新main构造新增/改动文件并以预期分支头更新，禁止覆盖并发修改。发布后回读文件哈希。

页面支持公司、指标、季度/半年/年度、完整统计范围、年份筛选、URL恢复、趋势、分页和CSV导出。每个图表只使用同币种、同范围、同期间口径的一个实际历史序列，模型预测和待核验期间只在表格显示。来源弹窗保留证据定位；本轮未上传原Excel或原报告，页面不提供虚构原件下载链接。

## Choice财务补充

`data/companies/choice.json`保存12个直接查询来源，`choice/*.json`保存148条财务记录。数据来自东方财富妙想的A股和美股金融数据接口，只使用接口明确返回的年报与中报实际值。A股为CNY，美股查询返回USD，后者原始列报币种尚未确认；未进行汇率转换。港股接口另有HKD与部分CNY结果，本轮未混入这套序列。

保留查询表名、报告期间、指标、返回原值和单位、Choice定位URL、内容哈希、读取日期以及返回精度说明。单位转换使用十进制计算：亿元/亿美元乘100得到百万相应币种，万元/万美元除100；不补充接口未返回的小数。现金及现金等价物、货币资金与现金及受限现金是三个独立指标。负债总额与债务独立，不把前者当有息债务。

Choice与原底稿采用不同basis，互不覆盖。同一财务面板的收入、利润和现金流固定公司、来源、期间、频率及币种；比率另校验期间口径。财务对照显示币种和利润定义，不比较跨币种绝对金额。未找到指定期间时不会以前期值回填；选择研究资料而该期间无收入记录时，可采用完整Choice财报组，并明确显示实际来源与币种。

更新先通过已授权Choice连接器查询并保存原始回执，随后只读导入：

```text
python scripts/import-choice-company-data.py --input-dir <回执目录> --root .
node scripts/company-overview-model.test.cjs
```

回执文件为`choice-a-share-raw.json`与`choice-us-raw.json`，结构为`{accessedAt, tool, query?, result: {data: [...]}}`。导入器只接收当前四家公司的已知财务指标及年报/中报期间；检查行列、重复主键和数值转换。它不会执行登录、认证或查询，不是自动同步任务。

经营趋势继续使用网站统一的数值柱形图与同比折线图。同比用同一统计序列的上一年同期间计算，OCC同比使用百分点；冲突基期和负值基期不给增长率。数据缺口不会连接同比折线。来源按钮、完整历史筛选及CSV导出可用于回查。
