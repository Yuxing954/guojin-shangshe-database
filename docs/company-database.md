# 重点公司数据库

## 公司研究档案

默认进入公司概览，展示业务画像、规模和扩张、ADR/OCC/RevPAR、收入利润、经营模式和收入结构、趋势、五年财务、现金流流动性以及跟踪重点。另设公司对照、历史明细、来源与缺口三个视图。对照支持固定季度和固定财年，缺少同期间数据时留空，不用上一期替代。净利润与归母净利润分开标明；期末规模和运营指标可能采用不同网络范围，每条来源保留完整定义。

`data/companies/profiles.json` 保存业务画像、代表性序列选择器、结构分母及跟踪问题；`supplements.json` 索引分片中的102条原披露核对记录。首旅和锦江的2026Q2经营、首旅全网络结构和单季财务、华住HWC/HWI结构等来自用户已有的三份PDF。来源哈希、PDF物理页码、原始单位和换算公式均保留；原PDF未上传。亚朵画像和结构来自已入库底稿，没有把业绩会前瞻表述当作实际结果。

读取时按完整业务维度和期间合并，原披露核对记录优先；原底稿保留在原分片文件中，界面及CSV保留原底稿值、定位和来源。合并后共4833条记录，其中159条模型预测、12条待核验占位。补充记录共102条，25条与原记录同键合并，77条新增。锦江2026半年报列示的2025Q2全服务型ADR/OCC/RevPAR与旧底稿存在3项差异；标为基期或来源差异，不擅自判定为重述、错误或同一基期。

同比只取上一年同期间、同频率、同币种、同业务和期间口径。入住率同比使用百分点；同比基期为零或负值时只展示增减额。原报告只给同比而未给基期值时标为报告披露，不反推基期。结构比率使用同期间、同单位、同币种的明确分母，差额保留，不归一化；首旅全网络与旧模型中国范围不跨口径拼接。现金、债务和现金流缺失处显示暂无数据。

原披露补充的固定格式更新入口：

```text
python scripts/import-hotel-disclosures.py --source-root "D:\\WORK" --root .
node scripts/company-overview-model.test.cjs
```

此适配器只对应本轮核对的PDF和取数表，运行前检查预设PDF哈希。源PDF变化时拒绝套用旧值，必须重新核对并更新映射。原经营底稿更新与披露补充分开维护，避免原导入器覆盖核对层。

公司页面 `company-database.html` 接入公司目录和逐公司历史索引和分片文件。首批使用用户 WORK 文件夹中的酒店底稿，覆盖标的池中锦江、首旅、华住、亚朵、君亭五家公司。四家公司已有专项数据，君亭没有找到专项经营底稿，明确显示暂无数据。它不是全球酒店上市公司全覆盖目录。

## 数据结构

- `data/companies/catalog.json`：公司身份、证券代码别名、指标目录、覆盖区间和按需读取路径。
- `data/companies/hotels/*.json`：逐公司索引；同名子目录中的分片保存经营、拓店、规模、收入利润、现金流、零售与同店历史。
- `data/companies/sources.json`：底稿相对位置、文件SHA-256、导入时间和核验层级。
- `data/companies/issues.json`：底稿冲突、勾稽差异、非当季开关店记录。
- 页面“导出完整数据”读取全部分片生成CSV，包含预测和待核验记录，须按状态筛选。导入器另生成本地CSV备份，仓库不重复保存大体积CSV。

每条观察值包含公司、期间、频率、期间口径、指标、数值、单位、币种、地区、档次/同店组、经营模式、统计范围、状态、来源ID、工作表/单元格或CSV行号、来源报告、PDF物理页码、原始值及可获得的原始公式。身份由来源位置和业务维度生成，不随数值更新改变。

`transcribed` 只表示从底稿准确转录，不表示本轮已经核验原始披露；`derived` 表示底稿中推算值；`forecast` 为模型明确标为E的2026—2028列；`pending` 为超出已收录实际报告期间的零值占位等。页面默认显示转录及推算历史，预测和待核验期间需单独开启。勾稽差异及冲突通过来源详情展示，未改写源值。

## 更新

使用Python和openpyxl只读导入，不保存或修改原工作簿：

```text

python scripts/test_hotel_company_data.py

```

这是显式手动更新入口，不是已安排的自动同步任务。导入器是首批固定格式适配器，新增公司/指标或来源表布局改变时需先核对表界、单位、期间和分类映射，再扩充适配器。不得按单元格颜色或文件修改时间猜测实际报告期。数据目录和观察值结构可复用于其他重点行业。

发布前检查源文件哈希、每条原始值与来源位置、重复序列键、实际/预测状态和前端筛选。GitHub读写使用连接器；基于最新main构造新增/改动文件并以预期分支头更新，禁止覆盖并发修改。发布后回读文件哈希。

页面支持公司、指标、季度/半年/年度、完整统计范围、年份筛选、URL恢复、趋势、分页和CSV导出。每个图表只使用同币种、同范围、同期间口径的一个实际历史序列，模型预测和待核验期间只在表格显示。来源弹窗保留证据定位；本轮未上传原Excel或原报告，页面不提供虚构原件下载链接。
