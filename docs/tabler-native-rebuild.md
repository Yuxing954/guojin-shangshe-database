# Tabler 原生重建记录

日期：2026-11-25（北京时间）

## 目的

前版仍保留大量旧页面结构和层叠覆盖样式，无法满足按 Tabler 模板完整重建的要求。本轮重写入口、导航和业务展示层，使用 Tabler 1.7.5 默认浅色双层横向导航与原生容器、栅格、卡片、表格、表单和按钮。深色模式使用模板原生主题变量。

## 保留边界

- 原仓库及 GitHub Pages 地址继续使用。
- 原始数据目录、报告文件、研究正文、纪要、行情快照、数据源和自动更新程序不纳入本轮 UI 提交。
- 行业、研究分类与公司业务定义继续使用原始纯模型。
- 全店/同店、累计/单季、国内/海外、地区/档次/经营模式/币种、官方/转引/测算与真实零值/缺失仍可区分。
- 原入口和常用查询参数保留；行业书签映射至新行业视图，不再加载旧业务 iframe。

基线提交：`a36cc4546c950dc794e2afaf632dcdc4d11d59f4`。基线 `data/` 树：`ef4ca8376722170614d2528761d3551c660be5c8`，包含 1,959 个原始数据文件。最终发布需核对数据树；本地用于验收的来源同步不进入 UI 提交。

## 实现与核验

新版入口只加载原版 Tabler、必要业务模型和 `scripts/tabler-app/`。旧样式与 UI 文件保留用于历史追溯，退出运行时入口。原版资源来源和校验值见 `scripts/vendor/tabler/README.md`。

新的 `tabler-integration.yml` 承接原生 UI 的核心业务、研究、行情和响应式验收，继续执行全部 Node 数据及分类测试。原数据导入和 Python 校验工作流保留；仅退休直接依赖旧 DOM 的布局工作流。UI 迁移不降低数值精度、来源、空值、分类或统计口径断言。

本地浏览器已核对公司全店/同店切换、来源原文、纪要全文、以及中美两组核心卡片五种宽度。其余正式发布结果以本次 PR 的 CI 和上线回读为准。
