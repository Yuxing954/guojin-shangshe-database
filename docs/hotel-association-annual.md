# 酒店年度结构

统计期2019—2025年；来源为2026版报告历年回溯，2018年未纳入。

中国大陆31省区市、客房15间及以上、年末在营可预订酒店；档次按OTA分类，非官方星级。

连锁为同品牌至少3家门店。档次占比图以客房数为权重：全部酒店内档次结构与连锁酒店内档次结构分别计算。分档次连锁化率以各档次全部客房为分母。

历史酒店数、客房数保留原报告万家/万间舍入值，客房同比沿用披露值。2025明细为精确数，不强行替换历史舍入序列。

连锁档次占比与连锁总规模由四档次规模加总测算；百分比显示舍入后可能不等于100%。

规模、城市等级结构占比及连锁化率均按客房口径。

2025年150间及以上酒店门店占比按14571/374694测算为3.89%，未沿用报告表中13.89%的笔误。

省份、城市、集团、品牌排名仅为2025年截面；品牌表覆盖外资、高端全服务、高端精选服务、中端、经济型，未含奢华品牌20强。

历年覆盖范围和分类变化可能影响可比性；本模块不包含ADR、OCC或RevPAR年度序列。
