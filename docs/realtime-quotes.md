# 实时行情

`quotes.html` 是独立的行情入口，替代导航中的“行情与工具”。首页、行业、公司、研究与行情共用导航；手机同样保留实时行情入口。旧 `database.html#coverage-live` 与首页旧行情锚点跳转到新页，其他历史模块继续保留。

## 展示与来源

- 公司目录沿用清单中的 `valuation` 数据集，只读取公司名、代码和行业；不把历史价格、PE或市值当成当前行情。
- 报价与指数来自腾讯 `qt.gtimg.cn`；走势来自腾讯分时与前复权K线接口。无私有自选股账户、凭据或服务器代理。
- 默认显示报价列表，可搜索公司、按A股/港股/美股和行业筛选，按涨跌幅或名称排序；涨跌图按需切换，缺失报价保持为空。
- 点击公司或指数打开走势弹窗；分时仅保留来源最新日期的常规交易时段，不接入跨日或午休后的错误时间点。日K和周K使用真实OHLC；只有来源明确返回前复权序列才标注前复权，其他序列注明源口径。美股走势使用报价返回的交易所完整代码。指数不标注前复权。
- 筛选、视图和当前证券写入URL，刷新后可恢复；公司研究链接进入已有公司详情。

## 时间和失败处理

页面每15秒请求一次，后台暂停，返回前台时恢复。刷新时间是读取时间，不是成交或报价时间。每只证券显示腾讯返回的报价日期与时间；A股、港股、美股分别按其市场日期判断“当日报价”或“上次报价”，不推断休市日或声称报价无延迟。

空报价、无效价格和无来源时间不会作为有效报价使用；缺失涨跌幅不计为平盘。请求前清理腾讯全局返回变量，防止上次响应被当成新响应。超时、网络错误、部分证券缺失时明确提示，并保留此前有效报价及其原始时间；不会以本地时间改写旧报价。跨市场汇总明确是各证券最近报价，不是同一交易时点的市场涨跌家数。

来源接口变更或某证券走势不可用时展示重试入口，不生成模拟走势。报价接口请求成功不表示上游已经发布新数据。

## 验证

`node scripts/quotes-model.test.cjs` 覆盖三种报价时间格式、时区、读取失败状态、空值与零值、市场筛选、缺失排序、OHLC合法性、分时跨日和常规时段过滤。原有市场K线、CSV解析、研究筛选和行业模型检查继续执行。

页面验证应包括真实报价与走势、旧入口跳转、断开报价请求后的旧值标记和恢复，以及375像素宽度下的导航、筛选和走势弹窗。
