## 页面与操作

独立入口为 quotes.html；全站导航和旧 database.html#coverage-live 跳转延续上一版。

- 三个市场指数缩成紧凑卡片。核心区域为左侧列表、右侧详情；窄屏上下排列，点公司后滚动到详情，支持返回列表。
- 全部覆盖、我的自选和五个重点行业直接切换；市场、行业、关键词取交集，不制造额外标的。搜索和分组状态保留在 URL。
- ☆ 收藏仅保存到当前浏览器，可取消；空自选显示添加说明，保存失败不阻塞使用。筛选重置不删除自选。
- 表头点击切换名称和涨跌幅排序。核心报价保留名称、本币价格、涨跌幅、来源时间；完整报价增加涨跌额、开盘、高低价。横向滚动限定在表格区域，字段偏好保存在浏览器。
- 单击公司联动详情；上一家/下一家按当前筛选列表切换，公司按钮上使用上下方向键同样可切换。
- 分时、日K、周K使用实际来源记录；日K支持20/60/120条显示范围，近1/3/6个月只是约定的交易日数量。图上指针及左右方向键可查历史点位。
- MA5、MA20从同一来源序列计算，不足窗口不补值。显示范围缩小时，计算仍使用此前有效记录；可关闭均线，分时禁用均线。
- 公司财务、行业数据及相关研究链接与当前证券对应。相关研究仅按明确公司名称或已知别名匹配本站近期索引，不因泛词“中国”匹配其他公司。按发布日期排序并去重，最多三条；无匹配或读取失败明确说明，不伪装为最新新闻。

## 数据与时间

公司目录沿用 valuation 数据集，只读取名称、代码和行业，不混用历史股价、PE或市值。报价来自腾讯 qt.gtimg.cn，走势来自腾讯分时和K线接口。美股使用来源返回的完整代码；只有返回明确的前复权序列才注明前复权，其他序列注明源数据口径。

按用户后续要求，正常报价请求起始间隔改为1000ms，每秒定时器到期即发起请求；未完成请求不重叠。仅在行情页面可见、行情模块激活且启用“每秒刷新”时运行自动检查。关闭自动检查后，手动刷新仍受相同间隔和单请求限制。隐藏页面取消待处理脚本并停止定时器，pagehide停止，pageshow（含浏览器前进/后退缓存恢复）重新检查，不补发漏掉的轮询。

读取时间与证券来源报价时间分别显示，列表、指数卡和涨跌图保留来源时间的秒；A股/港股/美股按市场日期判断当日报价或上次报价。来源时间相同则标注“来源时间未更新”，更旧的响应不覆盖较新报价。不推断休市日，不声称零延迟或每秒生成新行情。

空报价、无效价格和无来源时间不算有效报价；涨跌幅缺失不算平盘。每次请求前清理全局旧响应。失败和部分缺失时保留此前有效报价及原始时间，并明确提示。跨市场汇总不是同一交易时点的板块指数，不计算跨币种价格均值。

走势切换使用短期页面内缓存：分时15秒，历史周期5分钟；同一证券/周期的未完成请求共用一个结果，“刷新走势”也保留至少15秒的请求间隔。隐藏或离开页面取消待处理走势脚本，迟到响应不覆盖已切换的证券/周期。分时仅保留来源最新日期的常规时段，不生成模拟数据。

## 数据源、限频与部署核查（2026-10-09）

- 报价使用跨域script（腾讯GBK响应），一次合并请求覆盖公司与指数。无本站行情API、后端共享缓存、代理服务、鉴权配额或秒级推送服务。独立行情页报价、走势缓存均为页面内存，不是上游缓存。旧工具页另外有localStorage热力图缓存，本次保留来源时间、丢弃无来源时间的旧缓存，停止把本地重绘时刻标成行情更新时间。未增加绕过上游缓存或限频的机制。
- 按用户要求报价请求间隔设为1000ms。这是客户端请求节奏，不代表腾讯官方更新频率或每秒产生新报价；仍以返回的来源时间为准，不换域名、并发重试或代理绕过来源限制。
- 网络失败、超时或部分缺失：报价等待30/60/120/240/300秒后再尝试，成功恢复1秒间隔；手动点击、可见性变化、页面恢复不跳过等待。跨域script无法读取HTTP状态及Retry-After，故无法精确识别429或其等待时长；不通过换域名/代理/并发重试绕过限制。移除script并清理处理器可以阻止应用迟到结果，不保证撤回浏览器已经发出的网络字节。
- 旧database.html默认与#coverage-live均跳转quotes.html。留在旧重点公司/盯盘工具时，共用1000ms检查及1秒报价间隔；其他工具模块和隐藏页面不发报价请求，旧报价保留来源时间，并在证券提示展示。既有其他研究数据不因行情每秒请求而重新获取。
- 按用户后续部署要求，对照最新主分支 c274346 和成功的 Actions「pages build and deployment」运行 37891840207，确认沿用 GitHub Pages 从 main 发布。已同步主分支最新研究数据，不新增部署服务或修改 Pages 配置。站点 HTTP 缓存 max-age=600，行情脚本使用新版本参数以区分发布资源；每秒 UI 检查不代表静态文件每秒重新部署。

## 港美股走势修复（2026-10-09）

原通用 fqkline 控制器对港美股返回未复权序列；通用 minute 控制器对美股返回空日期和占位记录。独立行情页与旧工具页现在共用市场路由：A股 fqkline、港股 hkfqkline、美股 usfqkline；美股分时使用 UsMinute，港股保留 minute。美股完整来源代码（例如 usATAT.OQ）从实际报价读取，不猜测交易所后缀。

仅接受所选证券的返回记录。空日期、无效日历日期、异常时间、零价格和不足 OHLC 字段的历史记录不进入图表。只有实际非空 qfq 序列注明前复权，否则注明源数据；历史走势与报价日期不同继续明确提示。旧页港美股「近5日」使用日K并在加载提示注明，不能伪称多日分钟数据。分时请求至少间隔15秒、同 URL 共用未完成请求，隐藏/关闭弹窗/离开页面取消读取，等候美股报价后也再次检查页面状态。

tests/fixtures/tencent-charts-20261009.json 保存7份实际腾讯公开响应的测试摘录，含请求地址、采集时间、原始响应 SHA256；历史记录摘录首3与末26条，分时保留全部记录。覆盖港美股日/周K、正确分时，以及原美股空日期响应，便于回归验证；这不是行情生产数据。

实际浏览器读取观察：2026-10-09北京时间14:04附近，A股来源时间约14:04，部分港股来源时间约13:49，美股显示10月8日来源报价；每秒UI检查不会消除这些上游延迟。此为短时观察，不是接口频率保证。

## 方形热力图与稳定交互（2026-10-09）

- 热力图按面板宽度与公司数决定列数，正方形视口最高560px；桌面当前32家公司通常6×6，一屏展示。窄屏最多4列，以16家公司/页分页，保留全部筛选结果，不把遗漏公司隐藏在长条滚动中。涨跌幅字号随格宽调整，完整公司名称、代码、币种、价格、来源时间及失败状态可在色块提示与详情查看。
- 选择公司只更新选中状态、报价详情和走势，不重建列表、表头、行业按钮或热力图。重复点选当前公司不清空走势图；未过期缓存直接回显。未缓存公司用100ms合并快速连续选择，并显示明确加载提示，固定图表区域高度；加载提示不包含虚构价格或模拟走势。旧公司的迟到响应不可覆盖当前公司。
- 首次有效报价按选定排序排一次，此后默认固定位置，价格与颜色仍实时更新。可勾选“实时排序”恢复随报价排序；手动排序或筛选立即重排。重排同一组公司复用已有节点。搜索120ms防抖，报价详情逐字段更新；刷新按钮不再每秒切换文字和禁用状态。
- “暂停更新”停止报价轮询，不影响公司选择或走势查询；暂停时可手动刷新，继续遵守同一请求间隔和失败退避。失败保留来源数据与时间，并显示重试等待，不声称上游每秒更新。
- 当前范围可导出UTF-8 CSV，含市场、币种、源报价时间、读取时间和状态，不混用不同币种。空值留空、负数保持数值、文本防Excel公式注入。自选、字段、均线、图表范围、展示方式及实时排序偏好仅保存在当前浏览器。
- 热力图支持方向键、Home/End；跨页键盘选择自动显示当前公司，焦点不丢失。手机返回按钮聚焦当前展示方式的公司按钮。
