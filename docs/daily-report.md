# 国金商社日报

入口 `daily.html`，导航与首页均提供入口。每天北京时间16:00截点，重要数据窗口为截点前72小时，商社段子、市场观点与新闻为前24小时；区间左开右闭。每天云端自动任务执行，检索、运行和Pages发布可能晚于截点。

## 执行

1. 从最新main隔离检出，读取AGENTS.md。保留所有已有研究数据、源记录和日报历史。
2. 既有每小时观点任务负责采集知识星球；日报直接复用不可变CSV与增量manifest，不额外要求知识星球授权。原始发布时间决定窗口，不以导入时间替代。
3. 检索窗口内酒店、旅游、免税、餐饮、黄金珠宝、零售、教育、消费出海重要新闻，优先官方/公司公告及可靠新闻媒体；打开原文核验。将已核验内容追加到 `data/daily/news.json` 的items，去重保留旧条目。字段：id、title、summary（简洁事实摘要）、publishedAt（带时区、分钟级）、source、url、verified=true、importance（0—10）。仅有日期或搜索摘要不入24小时正式栏。更新checkedAt与status，不伪造数据、时间或来源。没有可核验新闻时如实记录。
4. `python scripts/build_daily_report.py --date YYYY-MM-DD`，日期为本次北京时间应生成日期。脚本默认在16点前使用前一日。输出latest.json、日期.json、index.json。重跑同日修订同一归档，保留其他日期。
5. `python -m unittest discover -s tests -p 'test_daily_report.py'` 与 `node --check scripts/daily.js`。提交仅日报源与产物；推送前fetch/rebase，冲突不得强制覆盖。
6. 核实GitHub Pages部署和线上 `data/daily/latest.json` 日期/截点/条数，失败如实报告。

## 筛选与覆盖

- 重要数据：从首页行业摘要、消费专题观测和宏观自动序列中的消费相关指标提取各指标最新点。通过Git历史比较窗口前后数值、统计期和同比，有实质变化才进入，最多30项。时间标签为入库文件提交时间，不是发布日期；统计期、来源、单位与累计口径独立保留。新接入历史序列标新增入库。并非全库每个数据模块均已接入。
- 段子：商社观点库；市场观点：全市场观点库。原文至少80字、明确时间，跨栏目按规范化正文去重。以标题含业绩/经营/同店/门店/利润/收入/政策/数据等词及正文百分比信息评分，同分按时间排序，各取12条。属于规则初筛，保留正文与原文链接供核对，不冒充人工研究判断。
- 新闻独立审核入库，观点不自动转成已证实新闻。当前新闻为空时界面显示“窗口内暂无已核验新闻”。
- 日期回看、复制、下载均以所选日期同一快照为准。每期记录观点源覆盖时间和新闻核验状态，详见数据说明页。
