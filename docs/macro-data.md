# 宏观数据与重要预测

一级导航 `macro.html` 共用现有 `site-shell.js`、`site.css`，静态部署无需新增服务器、数据库或前端依赖。手机导航分两行。中美切换、五组指标筛选、名称/代码搜索、URL恢复、近1/3/5/10年与全部历史、CSV下载、历史分页和失败重试均在本地快照上完成，不向浏览器发送密钥。

## 页面取舍

前台精选中美各20项核心指标，按“增长消费、通胀就业、地产投资、货币金融、外贸财政”分组。默认目录仅列已有真实数据的核心项；未接入项目归入可展开的“待补齐”。年度GDP增速和通胀单独放入“年度参照”，没有月度或日度核心数据时才自动展开。原72项目录及历史快照保留，年度总量、模型估计失业率、货币及股市占GDP等不再挤占默认页面。

CPI与核心CPI目录突出同比，非农就业目录突出相邻月就业人数增减（千人）；缺失准确基期时显示空值，不跳期比较。详情保留原始序列、频率、季调、发布日期和更新状态，来源授权及计算口径、历史明细按需展开。Polymarket保持中文标题、双语搜索及下载，筛选说明收起。

中国社零、CPI和全国居民收入复用站内“消费宏观”已核验的官方发布，读取同一份 `data/consumption-macro/observations.json`，保留真实发布日期、原文链接及官方同比。仅取社零当月值（不混入1—2月合并或累计）、CPI当月同比、收入季度累计；收入不推算单季。消费数据读取或核验失败时保留原宏观快照，不补数。原始宏观快照文件不被前端覆盖。

## 当前接入范围

目录共72项：中国36项，美国36项。每个国家覆盖经济增长、通胀、消费、就业、收入、工业、投资、房地产、贸易、货币信贷、财政、利率、汇率、金融市场。

- 世界银行 WDI：中美各16项年度系列，2000年至最近已完成年度。包含GDP、消费、就业、收入、工业、投资、进出口、广义货币、私人信贷、财政收入、实际利率、官方汇率和股市市值。WDI 是国际机构统一口径，不能替代本国最新月度发布；失业率为ILO模型估计。
- 美国 BLS：月度 CPI、核心 CPI（未季调）、失业率、非农就业人数、平均时薪（季调）。默认无密钥近3个日历年，可使用仅在更新环境中配置的 `BLS_API_KEY` 扩展至近15年。M13年度平均和上游缺失符号不作为月度值；修订脚注保留在快照。
- 美国财政部：最近2000个工作日的联邦政府债务总额，单位美元，当前余额，不是财政赤字。
- 中国 NBS/PBOC/海关/财政月度与季度数据、美国 BEA/Census/Fed 高时效数据以及授权行情：34项目录已具备展示与核验导入能力，但尚未实际接入，显示“待接入”和空值。尚无稳定获授权接口的来源不抓取内部未公开接口。未授权行情不从第三方图表或搜索结果补数。

本轮2026-10-09成功抓取37项，1项（美国WDI工业增加值不变价本币）上游无数据，34项待接入；以 `snapshot.json` 的实际状态为准。本模块提供覆盖目录与已接入系列，不能宣称所有指标均已自动更新。

## 时间、变化率与缺失值

`period` 是数据期间，`releaseDate` 是该值的真实发布日期；API不提供时为空，页面显示“来源未提供”。WDI `datasetUpdatedAt` 是数据库更新日，不能作为单个统计值的发布日期。`fetchedAt` 是最后成功获取时间，`checkedAt` 是最近尝试时间。`generatedAt` 只是快照生成时间。

水平与指数：同比匹配上年同月/季度，环比匹配上月/季度，公式为 `(本期/基期-1)×100`，不自动折年化。利率/增长率/占比等百分比指标比较为百分点差值；贸易余额等可能负值的口径使用原单位差值。基期非正、缺少严格匹配期、累计值和日度系列不推算同比环比。日度需要另外定义交易日对齐、月度聚合规则，累计值需要同口径官方变化率。未季调月度环比仍会受季节影响，页面标明季调状态。

API失败保留最后成功值并显示更新失败；本次无值保留旧快照并显示无新数据。年度滞后阈值800天、季度180天、月度100天、日度10天仅用于提示，不是官方发布日历。走势图不连接缺失期，不插值。下载保留原始值、口径、频率、单位、日期、来源链接与变化单位，并防止CSV公式注入。

## 更新与核验导入

```sh
python update/macro_data.py --cutoff 2026-10-09
python update/polymarket_data.py
node --test tests/macro.test.cjs
python tests/test_macro_data.py
```

更新脚本只使用Python标准库。所有API观测保留响应SHA256、请求或原序列链接、获取时间。年度接口限制单页，遇到身份不匹配、非有限数、未来期间、分页异常拒绝导入；不保存密钥到仓库或日志。宏观抓取并发4个，单请求25秒超时。接口错误写入明确状态后退出非零，便于更新任务发现异常。一次更新应遵守BLS日限额，避免反复刷新接口。

人工核验文件格式如下（仅结构示例，`observations`为空，不是示例数据）：

```json
{
  "series": [{
    "id": "cn-cpi",
    "unit": "%",
    "adjustment": "同比",
    "reviewedBy": "实际审核人",
    "redistributionApproved": true,
    "licenseBasis": "实际许可依据和审查记录",
    "observations": []
  }]
}
```

每条真实观测需要 `period`、数值型 `value`、ISO日期 `releaseDate`、该官方机构域名下的原始发布 `sourceUrl`。单位和季调口径必须与目录一致，不接受未来日期、重复期间、非官方来源或缺少再分发审核的记录。原稿应含该系列全部拟保留历史，导入会替换该系列已有快照。执行 `python update/macro_data.py --import-reviewed reviewed.json --import-only`，再检查差异并提交。未经核验的文件不能自动发布。

## Polymarket 重要预测

只读公开 Gamma API，不需要账户、钱包或交易密钥。扫描按24h成交量排名前600个公开活跃合约，关键词筛选“经济与利率 / 金融市场 / 政治与地缘”，排除体育、短时Up/Down、已截止、已关闭、归档合约及异常价格；每主题最多8个、每事件最多3个，共最多24个。范围有限，按量筛选不代表独立研究团队的重要性判断。当前概率为源 `outcomePrices×100`，不强制归一化，不造历史概率。

展示所有合约结果的隐含概率、24h成交额、流动性、价差、截止时间、源更新时间、获取时间和原始合约/结算规则链接。流动性低于1万美元和快照超过24小时会提示。标题和结果优先展示中文，英文原文可展开核对；中文和英文均可搜索，CSV包含中英双语。译名按完整英文标题匹配，来源改题时不会沿用旧译名；新题未翻译时明确标记待补充，并提供原文。结算以原始合约规则为准；分类为规则生成的中文标签。成交量、流动性缺失时显示“—”，不能当作0。市场价格与事件真实概率之间可能偏离。

[官方市场数据文档](https://docs.polymarket.com/market-data/overview)、[市场接口](https://docs.polymarket.com/api-reference/markets/list-markets)、[服务条款](https://polymarket.com/tos)。公开只读API与商业再分发许可是不同问题，后续扩大用途须核验许可。页面不提供下单和交易账户功能。
