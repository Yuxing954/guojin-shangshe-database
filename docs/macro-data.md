# 宏观数据

唯一一级类目为“宏观数据”，包含核心指标、消费专题、重要预测。旧消费专题地址继续可用，导航归入宏观数据。

## 核心目录

中国17项、美国14项，按增长消费、通胀就业、地产投资、货币利率、外贸收支分组。消费专题只列8项：社零、餐饮、网上商品、CPI、核心CPI、全国居民收入、全国居民支出、服务零售。原始细分类和年度数据保留在文件中，默认目录不再堆叠。

## 数据与授权

`data/macro/choice-registry.json`逐项定义准确名称、发布机构、频率、单位、起点、转换方式和可核验代码。用户已于2026-10-09明确确认Choice数据允许在此网站公开展示和下载。连接使用本机已有东方财富/Choice妙想MCP，接口为只读`mx_macro_data`；浏览器只读取静态快照，不持有密钥。MCP并非稳定的指标代码直查接口，可能返回相近序列；导入必须通过精确名称、机构、频率、期间、来源域名与已确认代码校验，多指标链接的代码排序不用于推断名称对应关系。

美国实际GDP取BEA官方工作簿T10101-Q的A191RL行；CPI、核心CPI、非农、失业率、时薪取BLS官方API完整历史；新屋开工取Census官方工作簿全国季调折年总量。其余审定序列从Choice获取。官方API和公开历史工作簿均已实际调用。BLS无需密钥的历史请求按三年分段。BEA和Census工作簿解析需openpyxl。

[Choice API说明](https://quantapi.eastmoney.com/AIGuide/PromotionPage?from=web)、[BEA开放数据](https://www.bea.gov/open-data)、[Census开工历史表](https://www.census.gov/construction/nrc/data/series.html)。

## 连续性与口径

多数序列从2016年起；城镇调查失业率从2018年、改革后的LPR从2019年8月、网上商品累计额从2019年、服务零售累计同比从2023年7月起。10年期美国国债为约5年日度历史，按实际交易日展示，不把周末和节假日列为缺值。覆盖报告包含实际起止、条数、要求起点、区间真实缺期及结构性非发布月份，不插值，不伪造历史。

GDP和PPI上年同期100指数明确减100转换为同比涨跌幅。当月、累计、季度、年化、季调与非季调分别标明；百分比序列的跨期变化是百分点差值。CPI的同比由对应官方指数准确基期计算。收入和社零官方同比不由舍入金额冒算。Choice金额存在“万/亿/万亿”舍入时保留脚注；消费页重叠期间保留已核验官方精确金额、发布时间和链接，补充字段另记Choice来源。未知发布日期为空，最近抓取时间不替代发布日期。

`automatic-series.json`是两个页面共用的补充数据，`coverage.json`是可机器检查的覆盖报告。原`observations.json`与`snapshot.json`保留。更新按审定定义增量合并，来源截短不删除既有历史；定义变化拒绝拼接，修订计数保留。单项接口失败保留历史，显示更新失败。数据覆盖不足和真实缺期明确显示，不能将“已接入”理解为所有月份都有发布。

## 更新

后续AI操作请阅读[宏观数据更新指引](macro-update-guide.md)，包含可执行命令、MCP补查、限流处理、测试和发布步骤。

本机后台运行：`python update/macro_auto.py --codex-config <本机配置文件>`。不提交本机配置、EM_API_KEY或原始认证请求。凭证可由环境变量EM_API_KEY提供，离线回执仅供审核重放，日常更新不使用旧回执。自动任务使用现有本机连接，核验后仅提交宏观数据文件并通过测试合并，沿用GitHub Pages部署。此类本机自动任务需要Codex和电脑运行；不会把本机密钥复制到GitHub。

GitHub的`refresh-macro.yml`仍是原有人工触发官方宏观/预测快照更新，不代表Choice已在GitHub托管运行。当前Choice自动更新由本机定时任务负责。

## Polymarket 重要预测

只读公开 Gamma API，不需要账户、钱包或交易密钥。扫描按24h成交量排名前600个公开活跃合约，关键词筛选“经济与利率 / 金融市场 / 政治与地缘”，排除体育、短时Up/Down、已截止、已关闭、归档合约及异常价格；每主题最多8个、每事件最多3个，共最多24个。范围有限，按量筛选不代表独立研究团队的重要性判断。当前概率为源 `outcomePrices×100`，不强制归一化，不造历史概率。

展示所有合约结果的隐含概率、24h成交额、流动性、价差、截止时间、源更新时间、获取时间和原始合约/结算规则链接。流动性低于1万美元和快照超过24小时会提示。标题和结果优先展示中文，英文原文可展开核对；中文和英文均可搜索，CSV包含中英双语。译名按完整英文标题匹配，来源改题时不会沿用旧译名；新题未翻译时明确标记待补充，并提供原文。结算以原始合约规则为准；分类为规则生成的中文标签。成交量、流动性缺失时显示“—”，不能当作0。市场价格与事件真实概率之间可能偏离。

[官方市场数据文档](https://docs.polymarket.com/market-data/overview)、[市场接口](https://docs.polymarket.com/api-reference/markets/list-markets)、[服务条款](https://polymarket.com/tos)。公开只读API与商业再分发许可是不同问题，后续扩大用途须核验许可。页面不提供下单和交易账户功能。
