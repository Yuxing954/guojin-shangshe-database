# 酒店节假日经营对标

看板入口：`hotel-holiday-dashboard.html`。

## 数据

`data/hotel_holiday_daily.csv` 保存酒店之家春节、清明、中秋、端午和国庆假期的逐日经营对比。原始来源工作簿保留在本地归档，不提交仓库；文件名、SHA256、行数、工作表、日期覆盖和导入时间见 `data/hotel-holiday-import-record.json`。

字段同时保留本期和源表指定对标期的入住率（OCC）、平均房价（ADR）及每间可售房收入（RevPAR），并保留假期日序、本期日期、对标日期、维度、分组和来源工作表/行号。中秋按源文件对比2024年，其余假期按源文件对比2025年。日期错位时按假期第几天对应，不把对标日期改写为本期日期。

## 指标

- 假期日均：对各假期日的日指标作简单算术平均，不按酒店数或房间数另行加权。
- OCC变化：本期日均减去对标期日均，单位为百分点。
- ADR、RevPAR变化：本期日均相对对标期日均的百分比变化；对标值为0或缺失时显示为空。
- 走势图按假期日序对齐；逐日表列示双方实际日期。分档位和分城市线级分别查看，不跨维度混算。

## 更新

在源工作簿保存后执行：

```powershell
python scripts/import_hotel_holidays.py <假期工作簿目录> data
```

程序校验五个来源文件、两张明细表的日期映射及唯一键，再覆盖生成CSV和导入记录。当前共275条酒店经营记录，覆盖春节9天、清明3天、中秋3天、端午3天、国庆7天；每个日期分别保留酒店档位和城市线级数据。
