# 餐饮经营跟踪

页面：`industry.html#dining`，独立地址：`dining.html`。业务数据：`data/dining/observations.json`；逐项核对：`data/dining/zsxq-reconciliation.json`；原图：`data/dining/source-20261023.png`。

2026-10-23通过知识星球CLI检索水木调研纪要-2.0，21组关键词召回141篇去重帖子，读取40篇完整正文。采用19篇原文核对47项，另对2项原图预计判断调整显示用词。全部采用项保留日期、链接、短摘及公司交流、专家或渠道等性质；转载内容不等同已独立核对公告。

同品牌、同期间数据优先采用知识星球；月度、假期、季度不互相替代。同店与单店、整体与内地、直营与全量样本不同，不能直接比较；采用不同指标的资料时在单元格及CSV明确标明，例如奈雪全量单店、古茗同店GMV。久谦堂食抽样资料不覆盖当前整体口径。更晚的月后反馈优先于月中前瞻。

精确同比增速转换为同比恢复率：100+原文同比百分比。区间、约数、超过及定性描述不变为精确数值。单月新来源拆开旧合并格时，剩余原图记录保留来源原始期间；季度值显示季度标签，不冒充单月值。

小菜园2026年8月、9月只有年初累计同店降幅，未获得可对应的单月同店销售，页面保留“预计同比微降或微增”。缺失数据不补零，原图判断不删去预计性质。数据说明与全部来源集中在`data-notes.html#dining`，业务页保留简短来源链接。CSV按每条记录输出真实来源、发布时间、原始期间及指标。
