# 餐饮经营跟踪

页面：`industry.html#dining`，独立地址：`dining.html`。唯一业务数据：`data/dining/observations.json`；证据：`data/dining/source-20261023.png`。

用户提供东方证券研究截图，2026-10-23转录；覆盖12品牌、20期间、149个原图单元格。原报告日期、页码缺失，未独立核对公告。

按原表保留指标：直营、整体翻台、直营／单店、店均GMV、同店GMV等。数值单位为同比恢复率%，并非同比增速；不跨品牌计算行业均值。

每条记录保留原文、品牌、指标、起止行、起止期间、来源及定位。纵向合并单元格保存为一个区间，边界按截图视觉位置转录，未确认为季度，不向单月复制。五一与春节独立保留，不与单月相加。原图空白留空。

仅精确单月百分比参与趋势。假期、合并区间、约数、105%+和定性描述不转换成精确月度数据；缺期断线。预计／测算保留原文和标签。表格筛选仅裁剪原始合并区间显示，CSV保留完整原区间。

更新时追加来源与记录，复核合并边界，运行 `node tests/dining-data.test.cjs`，检查页面、筛选、导出、手机及行业嵌入加载。详细说明统一在 `data-notes.html#dining` 展示。
