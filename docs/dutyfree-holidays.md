# 离岛免税节假日数据

2026年10月8日接入用户提供的《【国金商社】离岛免税数据库 20260908.xlsx》。本次导入29条有数值的完整假期记录、2条待补充记录及25条逐日/阶段记录。原工作簿不修改，不上传工作簿中的联系人信息。

入口：行业数据 → 免税 → 节假日经营数据；免税专题 → 节假日数据。支持假期、年份、对比指标筛选和带口径来源的CSV下载。完整来源记录位于 `data/dutyfree/holidays.json`，兼容原有字段的完整假期表位于 `data/dutyfree_holiday.csv`。

## 口径

- 金额亿元，购物人次万人次，每购物人次金额元。日均指标用同一期间总额除以原表统计天数；原表报告的客单价保留原值，可能存在四舍五入差异。
- 同比优先保留原表当年公布口径，包括清明2026年明确填入的同比，但不反推缺失的2025年假期总额。缺失同比仅在存在连续上一年同假期记录时计算。
- 2025元旦法定假期仅1天，使用元旦首日总额。1月1日至3日的同日历三天窗口、元旦首周、春节前三/四/五天及春运等在阶段区单列，不与完整假期加总。
- 原表2026中秋与国庆总额空缺；由空格生成的日均0及同比-100%不作为实际披露。2022国庆原表日期与年份的对应关系待核验，不推定天数及日均。
- 总额区域与汇总区域不一致时，展示总额区域对应口径，并保留汇总原值、单元格及原公式。原表公式反推的历史数值显示为“原表公式值”；本次没有独立回查海关公告。
- 春节假期中包含假设的3月日均测算未作为实际观测导入。

## 2026-10-09公开来源补录

- 完整假期由31条增加至35条：2019端午、2023端午、2020中秋国庆、2021国庆。阶段记录由26条增加至30条：2026端午前两天、国庆首日及前三天，另保留2020元旦原表同日历三天公式窗口。
- 2020元旦纠正为法定1天，购物金额0.54亿元、人次1.71万；原三天反推数值转存阶段区。2021元旦日均同比按3天/1天分别归一化，原文销售同比195.16%与原表公式保留，避免把同日历总额同比当作日均同比。
- 补上2026清明、五一、端午购物件数与披露同比，以及国庆69.68万件（新华社单独字段来源，既有央视同比来源保留）；新增2023端午后可计算2024端午日均/人次/每人次金额同比。披露增长率与数据库金额计算值可能因统计窗口、精度或修订不同而不一致，分别保留并标明依据。
- 来源清单与页面定位位于 `data/dutyfree/public-supplements.json`，发布日期、核验日期和日期依据各自保留；修改原表数据时保留 `workbook_baseline`。页面新增件数对比，CSV导出包含披露同比、计算口径与来源日期。
- 2025清明总额、2022国庆实际统计窗口、2026年9月单月及月度旅游人次的未核验缺口仍保留，详见页面“数据覆盖与待核验缺口”。本次未用增长率反推实际值，也未混用商务厅含有税销售口径。

执行 `python scripts/supplement_dutyfree_holidays.py` 可重放公开补录并同步兼容CSV。原Excel导入脚本也会自动重放，避免刷新旧工作簿时丢失公开更新。补录清单只接受已核实的数据，新增期间须先核对来源与日期。`python tests/test_dutyfree_supplements.py` 验证重复执行和旧工作簿刷新；`node tests/dutyfree-holidays.test.cjs` 验证数值、口径、两份数据一致与实际下载处理器。

## 验证和更新

安装openpyxl后使用 `python scripts/import_dutyfree_holidays.py <原工作簿路径> --source-version 2026-09-08 --imported-at 2026-10-08` 可复现本次导入。脚本按这份工作簿的标签和单元格结构解析；换版时需先核对工作表结构，不能直接套用到重排后的表格。

执行 `node tests/dutyfree-holidays.test.cjs` 检查空值、假期天数、元旦同日历窗口、春节口径、合并假期筛选和下载数据数量。更新时保持单元格定位与原公式，新增已披露期间不可直接把占位0改作实际0。网页导入日期和原表版本日期分别保留，不代表源数据在导入日发布。
