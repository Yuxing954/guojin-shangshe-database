# 商社研究网站

网站采用六个一级导航：首页、行业数据、宏观数据、公司数据、观点纪要、实时行情。所有独立页面共用 `site.css` 和 `site-shell.js`，在桌面使用左侧导航，在手机使用顶部两行导航。

- 首页：三条数据观察、四张行业卡、五条最新研究内容。
- 行业数据：酒店、免税、黄金珠宝、餐饮茶饮、跨境出海；一次查看一个指标，切换时间区间。历史记录分页，保留源 CSV。酒店同比使用去年同周相对变化；入住率以百分数显示。酒店和免税可进入专题，专题原有模块与筛选继续使用。
- 公司数据：从标的池读取公司，按行业筛选、搜索名称/代码/研究逻辑、按名称/市值/PE排序；打开公司详情查看估值、源数据日期、研究逻辑及全部财务记录。报告期按年份及季度排序，源表累计/单季标签保留，不跨币种换算财务值。
- 观点纪要：优先展示商社观点和纪要与附件，其他市场观点放在次要入口。搜索公司或关键词，支持七个板块、近7天/30天、自选日期和排序；板块根据覆盖板块、公司和标题关键词辅助归类。纪要分为可阅读摘要、文档附件、未转写音频，分别说明正文状态和原文件入口。新观点按需读取增量CSV中的完整正文；旧纪要仅展示已收录摘要，完整纪要使用原文件链接。近期检索覆盖标题、公司和内容预览，主动加载历史库后合并历史及增量正文，避免默认下载 11MB/59MB 的源文件。筛选和阅读记录保存在URL中，刷新恢复；首页最新研究直接进入站内阅读。对话框支持Esc关闭，正文使用纯文本，原文及下载链接只接受HTTP/HTTPS。
- 财报日历、酒店及免税专题：统一样式和导航，保留原有交互。行情与工具保留在独立入口，按模块显示，旧锚点依然可访问。

所有页面读取仓库已有数据，不把页面更新时间当作数据日期。读取失败显示重试提示，不以示例内容代替真实数据。历史库失败时仍保留近期索引。公司财务中不同报告期和币种按源表展示，原表的数据质量问题需要独立核对。

验证：`node scripts/site-data.test.cjs`、`node scripts/research-model.test.cjs`、`python scripts/test_home_snapshot.py`，以及来源合并、研究增量、原有行情、财报与日历测试。观点文库本轮浏览器验收覆盖公司搜索、近期和板块筛选、完整正文、摘要与文件分类、无结果提示、刷新恢复及首页阅读入口；全站改版此前另已检查五个行业、公司详情、专题入口和桌面/手机布局。

- 宏观数据：中美切换、14分类筛选、72项指标目录、官方真实历史数据、口径与日期追溯、CSV下载；Polymarket预测单独展示。数据接入缺口、API与授权依据见 [宏观数据说明](./macro-data.md)。
