# 商社研究网站

网站采用四个固定导航：首页、行业数据、公司数据、观点纪要。所有独立页面共用 `site.css` 和 `site-shell.js`，在桌面使用左侧导航，在手机使用顶部四项导航。

- 首页：三条数据观察、四张行业卡、五条最新研究内容。
- 行业数据：酒店、免税、黄金珠宝、餐饮茶饮、跨境出海；一次查看一个指标，切换时间区间。历史记录分页，保留源 CSV。酒店同比使用去年同周相对变化；入住率以百分数显示。酒店和免税可进入专题，专题原有模块与筛选继续使用。
- 公司数据：从标的池读取公司，按行业筛选、搜索名称/代码/研究逻辑、按名称/市值/PE排序；打开公司详情查看估值、源数据日期、研究逻辑及全部财务记录。报告期按年份及季度排序，源表累计/单季标签保留，不跨币种换算财务值。
- 观点纪要：商社观点、完整纪要文库、全部市场观点；列表只显示摘要，正文在原生对话框打开，支持 Esc 关闭。正文使用纯文本，原文及下载链接只接受 HTTP/HTTPS。近期观点使用仓库预生成索引，完整纪要读取小型 CSV；更早观点需要主动点击历史库按钮，避免默认下载 11MB/59MB 的源文件。索引截断过的内容以原文为准。
- 财报日历、酒店及免税专题：统一样式和导航，保留原有交互。行情与工具保留在独立入口，按模块显示，旧锚点依然可访问。

所有页面读取仓库已有数据，不把页面更新时间当作数据日期。读取失败显示重试提示，不以示例内容代替真实数据。历史库失败时仍保留近期索引。公司财务中不同报告期和币种按源表展示，原表的数据质量问题需要独立核对。

验证：`node scripts/site-data.test.cjs`、`python scripts/test_home_snapshot.py`，以及原有行情、财报与日历测试。浏览器验收覆盖五个行业切换、公司搜索/详情/排序、观点检索/正文/纪要下载、专题入口，以及 1280px 与 390px 布局。
