接入顺序

  1. 在SiteUI.registry登记入口、视图、公开参数和数据说明。
  2. 复用工作区工具与标准/紧凑密度；保留原生业务状态解析。
  3. drawPaired传入完整period、数值精度、单位、来源、口径；相同频率才声明syncGroup。
  4. 检查图表、明细、CSV、PNG和来源使用相同筛选。
  5. 在无本地状态的窗口打开分享链接；实测手机与失败重试。

保存配置仅在本设备；数据随更新变化。没有历史版本不提供冻结快照。
