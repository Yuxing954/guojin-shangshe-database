# 每日研究首页

`index.html` 是每日研究入口，一级导航为：首页、行业数据、公司数据、观点纪要。

首页仅展示三条研究重点、四张行业指标卡和五条最新商社观点/纪要。研究重点由现有数据提炼为观察提示，不假设存在当周新增数据。每项标注源数据日期；摘要生成时间单独显示。酒店超过 14 天、金价超过 7 天、月度经营指标超过 50 天时提示“待更新”。研究内容超过 10 天提示“内容待更新”。这些标记表示距数据期末的时间，不能证明上游已经披露了新数据。

首页仅请求 `data/home-snapshot.json`，不加载全量研究 CSV、图表库或实时行情接口。行情、财报日历及公司完整数据在底部折叠入口按需打开。

原完整看板保存在 `database.html`，独立酒店、免税、研究文库和财报日历继续使用。原 `index.html#sec-*` 等模块链接会跳转到完整看板的同名锚点。

更新仓库数据后运行：

```text
python scripts/build_research_recent.py
python scripts/build_home_snapshot.py
```

主分支数据更新和每日 Actions 同时生成研究索引与首页摘要；功能分支不自动写入摘要，避免干扰 PR 检查。两者只整理仓库已存在的数据，不抓取新的上游内容。检查摘要后将数据与摘要一起提交。首页研究列表默认合并商社观点与纪要，观点标题需命中核心行业或公司关键词，避免上游泛词匹配带入其他板块。列表按发布时间倒序、同日同标题去重，只保留五条；更多资料进入研究文库查看。关键词在生成脚本的 RESEARCH_TERMS 中维护。

校验：`python scripts/test_home_snapshot.py`。网页验收包含桌面和手机布局、来源展开、工具折叠、旧锚点转跳以及读取失败的重试和完整数据库入口。
