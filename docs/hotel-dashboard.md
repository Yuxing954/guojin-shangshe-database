# 酒店看板使用与维护

看板入口：`hotel-dashboard.html`。

## 使用流程

1. 选择数据周，默认“最新周”在每次加载时跟随全国最新数据；选择具体周次后固定查看历史。经营概览选择全国或重点城市。
2. 页首“周度指标显示”提供“同比增速 / 绝对值”，默认看同比。经营与供给卡片的大数字为增速或百分点变化，本周绝对值作为辅助信息；切换绝对值后两者交换位置。
3. 在同一张走势图切换三个指标，展示方式跟随页首开关。分档次与集团走势也跟随该开关。范围支持近1年、近3年及全部历史，截止所选数据周；同比曲线始终显示零基准线。
4. 城市对比使用统一数据周和比较基周；全国固定首行作参照。同比模式突出各指标变化，支持按每房收入、房价同比及入住率百分点变化排序；绝对值模式突出本周数值，保留辅助同比。可搜索、排序，点击城市返回经营概览。
5. “供给与集团”先显示全国15间及以上酒店供给与住宿餐饮投资：酒店数、房量、连锁房量同比及连锁率百分点变化，随后为月度投资累计同比。投资为住宿与餐饮合计、不含农户。集团表使用入住日期房价、价格与热度指数，年度市占率单独展示。

## 有效数据与供给口径

- 数据周选项随当前视图和地区调整，只提供存在有效本期数据的周。切换到历史不重叠的地区或视图时，优先选择不晚于原周的最近有效周，无更早周则选择首个有效周，并显示实际调整提示；不替换比较基周。
- 经营指标、分档次表和城市表仅展示有本期数据的指标及记录。当前范围完全缺失的指标禁用；早期仅有房价时仍可查看房价历史。
- 本期有值但基期缺失时，卡片和表格明确显示“绝对值 / 基期缺失”。整个图表区间没有有效同比时，图表显示本期绝对值并标明基期缺失；不把绝对值伪装成同比，不选择邻近基周补同比。
- 图表去除全空系列和首尾无有效数据的区间，内部缺失继续断线；真实零值保留。缺失整个供给或集团模块时改为紧凑状态提示，不预留大幅空图。
- 全国供给由15–29间、30–69间、70–149间、150间及以上四个原始规模档加总，排除15间以下和“全部”总计行。各字段必须四档均有有效非负值；早期分规模缺失但经营表直接披露15间及以上酒店数或房量时，可使用该同周同口径披露值。连锁字段缺档或缺值仍不可得，不补零或倒推。
- 连锁房量和分规模房量占比均使用同一个15间及以上范围；房量连锁率 = 四档连锁房量之和 / 四档全部房量之和，变化用百分点。经营概览的酒店与房间规模同样使用源表15间及以上字段。
- 已保存链接和历史周仍可使用；自动调整后的真实状态写回URL。源文件、经营OCC/ADR/RevPAR原口径、年度份额和月度投资原口径不变。

供给与投资趋势直接展示；分酒店规模明细、投资历史表、集团历史及年度份额按需展开。供给和投资分别保留周度及月度频率，投资图不跟随绝对值开关改成金额，未取得的金额显示“暂无数据”。

## 比较口径

- 默认比较上一年相同源表周号，不进行自动节假日错期调整；页面同时显示本期及基期起止日期。
- “同比口径与错期”支持手动选择上一年基周，用于研究者核对节假日对应期间。选择后，指标与明细标为“对比变化”；城市、档次和集团均使用该基周，不自动替换为邻近有值的周。
- 走势图中的同比始终按去年同周号计算；手选基周仅用于所选周的指标及表格。切换数据周时比较基周重置为默认。
- 手选基周后，页首按钮和本周指标 / 明细均标为“对比变化”。经营、集团和供给走势图仍为逐周同周号同比。供给连锁率变化用百分点，计数变化用%；房量占比和年度市占率保留自身口径。月度投资使用源发布累计同比，详见[投资指标说明](hotel-investment.md)。
- OCC变化为百分点；ADR与RevPAR变化为百分比增速。OCC基期为0可计算百分点差，价格或RevPAR基期为0不计算百分比。
- 未经确认的节假日对应关系不能自动当作同比基期。源表周号不强制转换为ISO周号。
- 缺失与异常记录不补零、不沿用前期值。图表沿源表周历排列；经营及分档次缺少某周记录时折线断开。
- 城市汇总数量使用有有效对比值的城市；全国不参与排名。全国加权口径保留源值，不通过城市均值重新估算。
- 年度份额按源值展示，六家份额不归一化；单项或合计超出有效范围的年度不进入走势图。

## 数据与页面边界

继续读取四个既有文件：

- `data/hotel_industry_weekly.csv`
- `data/hotel_group_weekly.csv`
- `data/hotel_supply_weekly.csv`
- `data/hotel_market_share_annual.csv`

2026-10-08界面简化没有修改以上数据文件，也没有修改其他页面的共享样式。页面展示数据截止日，而非页面生成时间。

图表范围、视图、地区、数据周、指标及比较基周写入URL片段，复制当前地址可复现选择；不包含凭据。`week=latest`表示每次加载跟随最新周，具体周号表示固定日期。次要数据源读取失败时，经营概览仍可使用，并在对应表格显示失败提示。

未指定显示方式时默认同比（`mode=change`）；历史链接的显式`mode=value`仍表示绝对值，可通过页首开关切换并分享当前选择。

页面独立样式和交互位于`scripts/hotel-dashboard.css`、`scripts/hotel-dashboard.js`，计算函数位于`scripts/hotel-metrics.js`。无额外框架或第三方图表依赖。

## 验证

在仓库根目录执行`node tests/hotel-metrics.test.cjs`。检查空值与零值、OCC百分点、价格增速、重复键、同周号及手动基期、各地区最新周、RevPAR量价恒等式、2017年历史、集团入住日期口径和年度份额范围。电脑和手机端另需验证城市跳转、日期切换、图表指标切换、折叠区域及横向表格滚动。
