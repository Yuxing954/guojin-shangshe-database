# 消费宏观

入口：`consumption-macro.html`，共用一级导航，使用现有 paper 主题、原生 JavaScript、SVG 和静态 JSON。无需服务端、密钥或新增前端依赖。

## 文件与证据

- `data/consumption-macro/sources.json`：原始发布标题、机构、日期、链接；人工核验的文旅/服务/出行数据逐条列为`reviewed`记录。
- `data/consumption-macro/evidence.json`：统计局原文表格单元格及相关统计段落。此次因原站返回JavaScript验证页，使用官方页面渲染文本提取，`retrievedUrl`记录实际官方镜像，保留渲染文本采集哈希，同时对留存单元格与统计段落计算可离线复核的快照校验和；不是原始HTML哈希。
- `data/consumption-macro/observations.json`：统一目录、来源和观测值；每条保留期间、期间末日、频率、口径、原始值、同比和来源ID。
- `scripts/import_consumption_macro.py`：标准库导入器。失败、缺列或重复记录会终止，不用空结果覆盖有效数据。
- `scripts/consumption-macro-model.js`：校验、筛选、同口径序列、最新记录与CSV导出。

“已接入”表示已有可核验记录，未表示已建立自动持续更新。静态页面读取已审核快照，避免跨域、密钥和官网防抓取影响日常使用。

## 更新

1. 在官方发布列表核验新增原文，确认数据期间、实际发布日期、名义/实际、累计/单季、平台与样本调整；将来源添加到`sources.json`。
2. `python scripts/import_consumption_macro.py --refresh --checked-at YYYY-MM-DD`尝试下载已审核的统计局来源。仅支持国家统计局发布表格；文旅、服务、交通数据需按原文人工核验后添加`reviewed`记录。遇验证页时保留现有快照，使用官方公开镜像或真实渲染页面提取，不绕过验证、不生成替代数据。
3. `python scripts/import_consumption_macro.py --checked-at YYYY-MM-DD`从证据离线重建。已核验来源是固定清单，这个命令不会自动发现新发布。
4. 执行下列校验，并同步manifest的记录数、覆盖说明及缺口；检查CSV和页面。

```text
node --test tests/consumption-macro.test.cjs
python -m unittest discover -s tests -p 'test_consumption_macro.py' -v
node --check scripts/consumption-macro.js
node --check scripts/site-shell.js
```

浏览器回归脚本：`node tests/consumption-macro.browser.cjs`。测试环境需安装Playwright和Chromium（`npx playwright install chromium`）；也可用环境变量`PLAYWRIGHT_MODULE`指定现有模块路径。脚本自带临时本地服务器，校验页面加载、分页、筛选、累计口径、待接入、日期、实际CSV下载、预计标签、390px手机布局及加载失败；截图写入忽略目录`.cache/macro-preview`，或由`MACRO_SCREENSHOT_DIR`指定输出目录。CI中的校验不依赖官网网络。

## 交互

总览支持类别、频率、接入状态和关键词筛选，12项分页；点击指标进入历史区。频率与口径独立选择，只绘制所选口径，月度1—2月合并值单独标注，缺月断线，累计跨年断线，假期不连线。日期筛选按期间末日包含两端。CSV与筛选结果一致，UTF-8 BOM、标准引号转义和公式注入保护；数值为真实0时保留0，缺失字段为空。
