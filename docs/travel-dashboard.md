# 旅游看板

入口：`industry.html#travel`，独立页：`travel-dashboard.html`。国内游、入境游、出境游分别切换，原三峡游轮入口保持独立。

## 数据

- `data/tourism/dashboard.json`：页面数据、单元格定位、来源、缺口和核验记录。
- `data/tourism/inbound-official.json`：国家移民管理局和文旅部官方披露输入；更新前必须逐项核对原始发布。
- 国内游：用户《国内旅游数据库 20261009》，假期主表A:H优先；辅助区仅补主表不存在的假期。同年同序位不重复导入。长白山E:G月度，九寨沟A:B日度。
- 出境游：用户《海外旅游数据库 20260612》，8个目的地有效月度序列。马来西亚期间错位记录隔离保留。文件名不是数据截止期，各目的地分别显示实际最新月。

两份输入文件的SHA256与每条记录原表定位均保存在JSON，未上传包含大量图片的原始工作簿。

## 更新

```text
python scripts/import_tourism_workbooks.py --domestic <国内xlsx路径> --outbound <海外xlsx路径> --output-dir data/tourism
```

Python只读xlsx的已保存缓存值，不调用终端刷新、不写回源表。导入须使用openpyxl。

## 口径

假期总量、日均量和人均花费分别计算。原表披露同比与同名假期测算同比分开保留；假期不同名或组合不同不强算。原表辅助区有重复/错位，不能整块当作新的独立序列。

海外接待中国游客为目的地统计，不加总为全国出境游客。月度同比优先上年同月值重算；基期没有值时沿用原表同比并保留标记。累计必须当年1月至当前月全部有数，否则为空；累计同比要求上年相同月份全部有数。缺期在时间轴保留空点。

国家移民管理局查验量属于双向出入境；外国人单向入境包含多种目的，不能当作文旅部外国游客。免签占比以外国人单向入境为分母，外国人双向占比以全部查验为分母。不能用双向查验的一半推算单向入境。

2026H1单向外国人入境2291.4万人次、同比20.4%；双向4590.6万人次、同比20.6%。参考图的12.4%实为外国人双向查验占比。最新官方2026Q3为单季，未拼成前三季累计。

文旅部年度入境游客数据与边检查验分图展示；原始披露有舍入差，分项不强行归一化。

## 核验

专项数据测试核对来源定位、假期单位和计算、缺期累计、官方单/双向区别、异常记录隔离及CSV。浏览器检查三板块、筛选、导出、桌面/手机宽度、嵌入布局、来源说明和读取失败后重试。部署后需回读生产入口与数据，提交成功不等于已上线。
