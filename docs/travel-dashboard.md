# 旅游看板

入口：`industry.html#travel`，独立页：`travel-dashboard.html`。国内游、入境游、出境游分别切换，原三峡游轮入口保持独立。

## 数据

- `data/tourism/dashboard.json`：页面数据、单元格定位、来源、缺口和核验记录。
- `data/tourism/inbound-official.json`：国家移民管理局和文旅部官方披露输入；更新前必须逐项核对原始发布。
- 国内游：用户《国内旅游数据库 20261009》，假期主表A:H优先；辅助区仅补主表不存在的假期。同年同序位不重复导入。长白山E:G月度，九寨沟A:B日度。
- 国内游全国季度量价：`data/tourism/domestic-official.json` 保存18次文旅部披露的季度累计量、官方同比及明确披露的单季人次。2022年作基期，页面默认2023—2025及2026最新（截至2026Q2）。不把节假日加总当全国季度。
- 景区更新：`data/tourism/scenic-official.json` 补长白山主景区2026年8—9月官方当月值、九寨沟2026-08-13—2026-10-23共72天实际接待值，记录直接文章URL和列表URL。原Excel历史保留，新增值不写回源表。
- 文旅企业客流：华侨城2024年1月—2026年9月33个月，原始公告来自巨潮资讯000069。含主题公园、酒店、商业等公司项目组合，非单景区、非同店。每期保留当月及累计，缺当月且相邻累计均为精确数值才差分。2023年“近/超”累计数保留限定词，只作披露留存，不作精确差分基期。
- 出境游：9个目的地；用户《海外旅游数据库 20260612》为基础，马来西亚和新加坡采用官方月度补充。文件名不是数据截止期，各目的地分别显示实际最新月。
- `data/tourism/history-supplement.json`：已核对的官方月度快照和年度比较基期。马来西亚2022—2025年48个月（KPI 2025印刷页20/PDF第23页，China/TOURIST）；新加坡2022年1月—2026年8月56个月（居住地China，官方数据2026-10-10更新）。保留原工作簿数值和马来西亚36条原日期，不覆盖用户文件。

两份输入文件的SHA256与每条记录原表定位均保存在JSON，未上传包含大量图片的原始工作簿。

## 更新

```text
python scripts/import_tourism_workbooks.py --domestic <国内xlsx路径> --outbound <海外xlsx路径> --output-dir data/tourism
node tests/travel-data.test.cjs
node tests/travel.browser.cjs
```

Python只读xlsx的已保存缓存值，不调用终端刷新、不写回源表。导入须使用openpyxl。

`update_domestic_tourism.apply_domestic` 在旅游历史补充后自动生成 `domestic.quarters` / `domestic.quarterYtd`。单季出游人次优先官方分季披露，无单季值时以相邻年初累计差分；Q2—Q4花费按相邻累计差分并标“测算”。缺前一累计期则留空，不能从零起算。人均花费=亿元/亿人次，单季与累计各自比较。已披露同比保持官方口径；未披露单季同比和人均同比按上年同口径值计算。保留每项指标的本期、前一累计期和上年比较期来源，CSV导出携带全部链接。

官方披露含舍入及可比基期差异，例如2026Q1花费1.86万亿元、同比2.9%，不以本库2025Q1的1.80万亿元重算覆盖。差分花费同比只是披露值测算。2026Q3全国数据未从统计目录取得，页面不填。季度与假期筛选独立，季度默认近三年；筛选空期显示暂无数据。

导入末尾自动调用 `update_tourism_history.apply_history`，防止重新导入时丢失已核验历史。仅调整官方补充时可执行 `python scripts/update_tourism_history.py`。补充文件不联网自动更新；追加新期前须核对官方表的指标定义及基期。

景区与企业追加流程：在官网固定统计栏目或公司月度经营公告核对新期，在`scenic-official.json`追加原始记录、发布日期、URL、口径和原文限定词，再运行 `python scripts/update_scenic_tourism.py`。该模块也接入原Excel导入末尾，重新导入不会丢失已核验的新景区数据。九寨沟同月日同比不是星期或假期错位调整；长白山新增官方同比保留披露值，不以原表舍入基期覆盖。

连续数据候选检索结果见`scenic-official.json`的`availability`：黄山存在零散单月新闻及定期报告，泰山存在季度经济运行披露；黄龙、四姑娘山、达古冰川、峨眉山、九华山本轮尚未取得可逐期核验的完整高频序列。未接入不等于不存在；不使用门票预售、承载量或节假日人次冒充正常日/月序列。详细检索状态进入页面数据说明。

2023—2025是三个完整年度，2026年按最新已披露月/季度保留。出境游默认显示“近三年＋最新”，另列目的地全年量、年度同比和文旅部全国出境旅游量。全年量只汇总完整12个月，2026年累计不当全年。全国同比保留官方可比口径。

入境查验补齐2023—2026年第一季度、上半年、第三季度历史，2022年全年仅作更早历史；2023—2025年度入境旅游单列。表格并列总查验、内地居民、港澳台居民、外国人双向、单向入境、免签入境及各自官方同比。外国人单向及免签图同时显示量和同比，外国人双向同比另图展示。

缺口：泰国2023年月度未取得已核验2022月基期，因此月度同比空值；官方2022全年27.3567万人次可用于2023年度同比。越南2023年1月同月基期缺失。文旅部2023年全国出入境旅游同比缺可比披露。2026Q1免签29.3%为官方原文，与2025Q1问答657万人次不直接勾稽，保留差异，不反推修改。所有缺口详见dashboard.json notes。

## 口径

假期总量、日均量和人均花费分别计算。原表披露同比与同名假期测算同比分开保留；假期不同名或组合不同不强算。原表辅助区有重复/错位，不能整块当作新的独立序列。

海外接待中国游客为目的地统计，不加总为全国出境游客。月度同比优先上年同月值重算；基期没有值时沿用原表同比并保留标记。累计必须当年1月至当前月全部有数，否则为空；累计同比要求上年相同月份全部有数。缺期在时间轴保留空点。

国家移民管理局查验量属于双向出入境；外国人单向入境包含多种目的，不能当作文旅部外国游客。免签占比以外国人单向入境为分母，外国人双向占比以全部查验为分母。不能用双向查验的一半推算单向入境。

2026H1单向外国人入境2291.4万人次、同比20.4%；双向4590.6万人次、同比20.6%。参考图的12.4%实为外国人双向查验占比。最新官方2026Q3为单季，未拼成前三季累计。

文旅部年度入境游客数据与边检查验分图展示；原始披露有舍入差，分项不强行归一化。

## 核验

专项数据测试核对来源定位、假期单位和计算、缺期累计、官方单/双向区别、异常记录隔离及CSV。浏览器检查三板块、筛选、导出、桌面/手机宽度、嵌入布局、来源说明和读取失败后重试。部署后需回读生产入口与数据，提交成功不等于已上线。
