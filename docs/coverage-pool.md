# 商社行情覆盖池

公司数据页已撤除；旧 `companies.html?company=...` 只保留到 `quotes.html?symbol=...` 的兼容跳转。首页、行业、研究与站内搜索均指向行情覆盖池。财务/估值原始历史表保留为归档，不为新增公司维护重复估值和财务数据。

## 单一目录

`data/coverage-companies.json` 是行情、行业关联公司和公司搜索索引共用的证券目录。共107家：原有32家，新增75家。字段仅代码、名称、研究分组、别名及核验来源；不含股价、财务预测或推荐级别。原有32家公司来自原覆盖表，新增身份由腾讯实际公开响应核对代码、简称、来源时点，记录批次请求URL与SHA256；更名/ST简称使用响应原值，旧简称作为别名。研究分组不是交易所行业分类，免税组包含机场/运输等产业链相关公司。

新增覆盖旅游、免税链条、黄金珠宝、跨境出海、餐饮茶饮、商超零售、美妆个护、教育人服、电商平台及潮玩生活方式。保留现有腾讯请求合并、慢请求防重叠、后台暂停、失败退避和来源时点，不因覆盖数量增加而提高请求频率。热力图按现有容量分页，列表及导出保留全部筛选结果。
