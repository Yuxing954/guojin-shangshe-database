# 导航组件契约

规范入口：[全站显示规范](site-presentation.md)。导航结构和正式入口来自 scripts/site-ui.js，样式唯一维护在 scripts/site.css 的 components 层。

| 层级 | 组件 | 适用范围 |
| --- | --- | --- |
| 全站 | site-nav | 六个现有主入口；手机横向滚动；数量从配置读取 |
| 模块分类 | site-subnav site-subnav--category | 行业板块与宏观栏目；下划线选中，44px触控区 |
| 内容视图 | site-subnav | 公司、国家、专题内容；白底描边、蓝底选中 |
| 图表内部 | site-segment | 数值/同比、合并/分开等；浅底分段，保留业务语义 |

同一层级不能因模块而另写颜色、字号、圆角和间距。原有ID和状态字段保留；新按钮用 aria-pressed，页签用 aria-selected，链接用 aria-current=page。仅允许一个有效选中项；hidden必须同时阻止隐藏内容的布局与操作。悬停、选中、禁用、focus-visible遵循共享规则。

URL必须与视图一致，刷新/后退/复制链接可恢复；默认值由模块明确声明，不能用布局脚本猜测。筛选的日期、指标、数值/同比属于图内控件，不附加内容页签样式。

宏观入口为 macro.html?view=indicators，核心指标、地方社零、FedWatch、Polymarket 由 macro-navigation.js 生成。地方社零默认城市分线，近期覆盖较全的一期；地区拆解保留真实发布月份和可用维度。消费全景独立入口已退役，底层数据保留。

最新 main 已撤除黄金导航，旧 gold URL 仍兼容到酒店；本轮不恢复旧入口。餐饮现为单页业务结构，无旧测试要求的二级视图按钮。公司数据库当前使用酒店公司选择器，不恢复旧 db-tabs。

浏览器检查读取实际组件层级比较计算样式，并覆盖选中、键盘焦点、行业嵌入及宏观国家切换。更新测试必须保留有效行为断言，退役入口改验兼容行为。
