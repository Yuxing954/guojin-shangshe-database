# 页面与数据工具

[返回项目首页](../README.md) · [维护文档](../docs/README.md)

浏览器代码按功能目录归档；共享脚本及现有更新工具保留稳定入口。移动文件时同时更新 HTML、测试和工作流。

| 前缀 / 文件 | 用途 |
| :--- | :--- |
| `site-*` | 共享布局、数据读取、图表与交互 |
| `industry-*` | 行业入口、嵌入看板与加载状态 |
| `hotel-*` | 酒店经营、集团、假期、年度结构与周度产品 |
| `domestic-hotels*` | 国内酒店公司页面和模型 |
| `overseas-hotels*` | 海外酒店公司页面和模型 |
| `macro-*` / `consumption-*` | 宏观与消费模块 |
| `dutyfree-*` / `cruise-*` | 免税与游轮模块 |
| `research*` | 观点纪要展示、模型与资料处理 |
| [quotes/](quotes/) | 股票及黄金行情的页面脚本、模型、轮询与样式 |
| [calendar/](calendar/) | 财报和重要数据日历的页面脚本、模型与样式 |
| `build_*` | 数据汇总和页面快照构建 |
| `import*` / `update*` / `sync*` | 数据导入与增量更新 |
| `*.test.cjs` | 部分模块的模型检查 |
| `assets/` | 图片、标识与应用图标 |

更新数据前先读[对应模块维护文档](../docs/README.md)，不要仅凭脚本文件名运行全量刷新。
